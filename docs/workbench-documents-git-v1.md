# 文档阅读与 Git 侧栏第一版

## 范围与验收

用户确认直接实现，沿用现有 Electron / React / Vite 结构及应用配色，不改主 Agent 循环。

1. 打开 Markdown 时默认显示排版阅读视图；可切换源码、编辑；未保存内容不会因切换阅读丢失。支持标题、表格、任务列表、代码高亮、链接和本地图片；图片/链接遵循现有工作区授权，远程图片由用户点击后在浏览器打开，不自动联网加载。
2. 打开 DOCX 时保留文档样式与页面结构；提供适应宽度、原始页面与缩放。复杂 Word 排版仍为近似预览，原文件可外部打开；损坏文件必须显示错误，不停留空白。
3. 空侧栏、加号菜单第六项为 Git，前五项不变；按任务/工作区恢复标签。
4. Git 显示分支、工作树/暂存改动、差异和最近提交；支持按文件暂存/取消暂存、仅提交已暂存内容、手动获取及确认后推送已有远程跟踪分支。
5. 不自动执行 git init、配置身份、合并、重置、强推、删除或清理。副作用回归仅使用新建临时仓库，不操作当前实际仓库。非仓库、子目录工作区、冲突、未设身份、过期快照与网络失败必须给出错误反馈。

## 设计与边界

- 文档渲染独立组件，文件编辑器仍负责内容、草稿与保存；Markdown 的相对链接以文档所在目录为基准。
- DOCX 在限制脚本、网络与嵌套页面的 iframe 中呈现，避免文档样式污染宿主，保留页面尺寸与嵌入字体。忽略 HTML altChunks。
- Git 由主进程工作台 IPC 分发至专用服务。只允许固定操作、shell=false、字面文件路径、限时限量输出；不接受任意 git 参数。写操作使用版本校验、仓库级串行化，不覆盖文件内容。
- 视觉：Industrial/utilitarian 工具型界面；继承 AporiaX 品牌字体与浅深色变量，覆盖技能默认的字体/配色禁用建议，不引入新主题。Git 列表、状态与红绿 diff；文档阅读区留白与滚动分离。

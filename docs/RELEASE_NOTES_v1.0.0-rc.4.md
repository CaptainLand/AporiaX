# AporiaX 1.0.0 RC4

RC4 改进桌面聊天、主题一致性和模型选择，并加入 Claude 适配与重复空转保护。仍是正式 1.0.0 前的候选版本。

## 桌面界面

- 明暗主题共用白天版的尺寸、间距、圆角与滚动条规则，仅保留配色差异；切换主题不再因布局变化移走阅读位置。
- 项目和任务列表更紧凑，移除重复图标、层级竖线和重复“项目”标签；标题与列表使用正文的普通字号，搜索框使用灰色聚焦边线。
- 主聊天与侧聊输入框默认高度、上下边缘一致；Witness 保留小间距，多行输入和实际运行／暂停提示仍正常显示。
- 主聊天与侧聊复用模型选择面板，统一搜索、来源分组、模型列表、选中／禁用状态和配置入口。侧聊模型选择仍独立，主任务专属思考设置不联动到侧聊。
- 扩展页头改为“Skills 和 MCP”，精简执行记录和输入区的重复通用说明；保留错误、安全和实际状态提示。
- 支持选中对话后复制或添加引用；改进 Git PR、工作区和账户界面，并更新 Windows 快捷方式、任务栏与托盘图标。

## 模型调用与任务保护

- 根据 Claude 模型 ID 识别思考能力，不再仅依赖中转域名。Opus 5.5 的档位映射采用统一规则，新选择默认 Medium，已有显式设置保留。
- 不自动改换供应商或接口协议。中转站仍需支持所选接口及思考档位，其首字延迟和计费行为取决于服务商。
- 重复规划或反复读取相同证据且没有实质进展时，默认六次后保存进度并暂停，需要用户检查后继续；正常推进和实时进程轮询不因该保护而被误停。
- 本轮通过原生文件工具创建并登记、内容与身份未变化的临时自检脚本可免删除确认清理，并保留恢复备份。用户文件、工作区外文件、未登记脚本、显式权限限制及异常恢复确认不放开。

## 本机诊断与隐私

响应诊断默认关闭。使用启动参数 `--capture-next-model-response` 时，仅旁路观察下一次实际请求尝试，在本机用户数据目录保存接口公开返回的可读思考和正文；不增加模型调用、不上传 Cloud、不记录请求输入、鉴权头或工具参数。加密／隐藏的思考块不可读取，这不代表完整内部推理。返回文本本身可能包含私人信息，诊断文件用完后可由用户清理。

手机应用、文件／项目／对话远程同步及头像前端展示未恢复。全局工作区外文件权限继续默认关闭。

## 更新与安装

- 安装版和便携版均提供 Windows x64 包；更新入口沿用优先 GitHub、失败回退国内镜像的规则。
- GitHub Release 设置为 Latest 以兼容现有默认更新通道，产品仍是 RC 候选版，并非正式 1.0.0。
- Windows 包暂未使用可信代码签名，系统可能提示未知发布者；请核对官方发布地址与 SHA256 清单。
- 本次不部署 Web／Cloud 后端，不调整账号数据、额度规则、最低客户端版本、域名、安全策略或正式版许可证。

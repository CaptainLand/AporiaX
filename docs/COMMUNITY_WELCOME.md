# Welcome to AporiaX Discussions / 欢迎来到 AporiaX Discussions

Every problem begins with an aporia.

This is the place for questions, early ideas, workflow stories, and examples of what
you created with AporiaX. Bug reports with clear reproduction steps should use the
Issue templates; security or credential concerns must follow `SECURITY.md` and should
not be posted publicly.

You can start with any of these:

- Which task did you try first?
- Did Route, Evidence, and Anchor make the agent easier to trust?
- Which model provider and workflow should AporiaX support next?
- Show a document, presentation, spreadsheet, or project you created.

---

这里适合提出问题、讨论早期想法、分享真实工作流，以及展示你使用 AporiaX 创作的内容。
可以稳定复现的问题请使用 Issue 模板；安全问题和凭据泄露请按照 `SECURITY.md` 私下报告，
不要公开发布。

你可以从这些话题开始：

- 你首先让 AporiaX 完成了什么任务？
- Route、Evidence 与 Anchor 是否真的提升了可信度？
- 你希望接下来支持哪个模型、MCP、Skill 或工作流？
- 欢迎展示你生成的文档、PPT、表格或代码项目。

Thanks for being here. 感谢你愿意从一个疑问开始。

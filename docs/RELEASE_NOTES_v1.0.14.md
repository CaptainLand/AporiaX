# AporiaX 1.0.14

- Witness 在执行中只记录变化，结束时保留完整快照，减少长任务的磁盘占用。
- 桌面端只保存有变化的任务。写入较慢时会合并中间更新，保留最新状态，不反复处理未改动的历史记录。
- 流式输出时复用旧回复。执行记录、工作区和项目知识在首次打开时才加载；切回任务时恢复之前的阅读位置。
- 长对话减少屏幕外消息的绘制，仍可查找和选中消息。如遇显示问题，可从任务右上角菜单选择「完整渲染对话」。

## 安装说明

- 仅提供 Windows x64 安装版。覆盖安装前请从系统托盘退出旧版。
- 个人 ChatGPT／Codex 账号接入仍只在本地开发版可用。
- 安装包未进行 Windows 数字签名，系统可能提示未知发布者。
- Cloud 令牌刷新与模型请求并发时偶发的 401 未在本版修复。

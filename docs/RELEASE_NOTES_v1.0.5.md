# AporiaX 1.0.5

Windows x64 · 2026-10-21

## 对话与交付

- 回复优先展示交付结果和最重要的一两点，补充说明、常规验证记录收进「查看完整回复」；真实失败和需要处理的风险仍明确展示。
- 统一正文、阶段进展的轻文档排版，收紧字号和间距；成员交付卡片默认突出结论与关键问题，完整报告及技术信息按需展开。
- 请求进度显示下载 Token 数量，不再展示上传 Token；移除普通任务运行中的重复提示。

## 任务执行

- 改善子 Agent 的委派、续办与后台协作，默认不再使用固定轮次及累计启动次数截断任务；并发上限、权限、范围、暂停和取消边界继续保留。
- 优化删除文件工具、补丁格式兼容及错误提示；删除使用明确路径并保留恢复信息。
- 优化简单任务的历史上下文投影，原始记录与用户约束仍保留。
- 改善 GPT 系列的思考强度映射和流式文本衔接，减少流式与最终文本不一致引起的误报。

## 工作侧栏与技能

- 临时聊天使用统一的对话、输入框和 Witness；与主任务独立执行，关闭标签时停止并丢弃临时对话，文件冲突及恢复信息独立保留。
- 改善 HTML 预览及文件打开方式。
- 新增内置技能「qq号锐评b50」，按用户明确请求查询并分析公开 B50 数据，不自动查询或绕过成绩访问限制。

## 发布边界

- 提供 Windows x64 安装版和便携版，沿用原目录覆盖安装，不删除其他安装或用户数据。
- 使用现有正式账号与模型服务；本版不修改云端计费、模型网关或公共额度池。
- 个人 ChatGPT／Codex 账号接入继续仅供本地开发测试，在正式安装包中不可用。
- Windows 文件尚未进行 Authenticode 签名，系统可能显示未知发布者提示。

# AporiaX 1.0.0 Preview 3

版本：`1.0.0-preview.3` · Windows x64 · 2026-09-24

本版仍是测试预览版，不是 1.0.0 正式版；作为普通 GitHub Release 设为 **Latest**，让现有桌面用户能够收到更新提示。

## 相比上一个公开 Preview

- **Cloud / Web / Desktop 联动**：内置当前内测站点的 HTTPS 配置，点击「登录 AporiaX」即可在系统浏览器授权，无需手动启动网页、终端或 SSH 隧道。旧私有预览配置不会覆盖公开版本的站点。
- **账户中心与教程**：左下角账户菜单新增网页账户中心入口；首次模型配置和应用内教程入口帮助添加自己的 API。账户菜单文字对比度改善，暂不支持的远程功能明确置灰。
- **Cloud 模型适配**：对齐服务端提供的 DeepSeek V4.1 Flash、原生图片能力、可用状态与额度；移除旧 Qwen 图片代理路径。可用模型及价格以账户中心与服务端为准。
- **恢复时保留请求身份**：主 Agent、子 Agent 和外层恢复使用持久化请求身份与回执；未确认的请求不会直接换身份重发，降低重复调用、重复计费风险。未知结果仍可能需要人工确认，不承诺所有中断都能无损恢复。
- **更新链路**：安装版支持检测、下载与确认重启更新；便携版提示到 Release 下载。补齐 Preview 数字版本及未来正式版的版本比较。
- 保留首次 Preview 的断网等待、睡眠唤醒续跑、按需项目知识、最新在前的执行记录、Agent 激活与 Builder 并发统计。

## 下载和升级

- 推荐：`AporiaX-Setup-1.0.0-preview.3-x64.exe`。
- 免安装：`AporiaX-Portable-1.0.0-preview.3-x64.exe`。
- 普通 AporiaX 用户可在 **设置 → 关于 → 检查更新** 手动检查；后台检查有时间间隔，不保证发布后所有电脑立即弹出提示。
- **独立 AporiaX Beta**（`1.0.0-preview.2.beta.1`）此前关闭了公开更新检测，需要手动下载一次。其用户数据目录与普通版不同，本次不会自动合并或删除 Beta 数据。
- 普通版延续原应用标识与数据目录。更新前请结束任务并正常退出；旧 Cloud 登录可能需重新授权，自带 API、项目和本地任务不随站点变更上传。

## 内测边界

- 当前站点为 <https://101.43.44.160>；`aporiax.cloud` 的备案与域名切换尚未完成。
- Cloud 自助注册容量暂为 **20 人**，全站模型费用保护阈值为 **每日 ¥5**；达到限制时 Cloud 服务可能暂停或拒绝新注册。自带 API 路径独立，不自动切换扣费。
- 云端执行远程任务与手机远程文件访问尚未开放；不要把置灰入口理解为可用功能。
- 安装包尚未代码签名；请从此仓库下载并核对同版 SHA-256 校验文件。
- 本版许可证仍为 MIT；计划中的正式版许可证变更尚未生效。

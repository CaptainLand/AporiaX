# AporiaX 1.0.7

Windows x64 · 2026-10-22

这一版重点减少任务中途卡住、明明有结果却显示整轮失败的情况，同时改进文件定位、浏览器验证和工作台体验。

## 回答与任务收尾

- 普通文字回答即可结束，不再要求模型必须填写固定的结束字段。结束参数缺失或不规范，不会直接丢弃已有回答。
- 空回复、损坏的工具响应等异常发生后，在安全条件允许时，额外尝试一次只输出文字的收尾回答；不会重跑文件操作或放开工具权限。
- 最终回答已送达后，后续记录保存或连接异常不再把它替换成红色整轮失败。重要错误和未完成事项仍保留，不把“已回复”当成“全部验证通过”。
- 正常结束时同步计划状态；部分完成、受阻或中止时保留未完成项，执行记录与恢复数据保持一致。
- 账号、额度、用户停止、明确的请求预算，以及计费结果不确定等边界继续保留；无法取得最终回答时仍明确说明原因。

## 文件与代码定位

- 新增按文件名和路径查找的工具，不必为了找文件扫描所有正文；文件列表使用缓存，并在本地文件变化时更新。
- 内容搜索加入统一超时、取消和进展提示，避免大目录长时间没有反馈；截断结果不会被当作“没有找到”。
- 修复安装包内搜索程序的路径适配，侧栏搜索支持防抖、取消旧请求和显示实际错误。
- 改进工作区链接的路径归一化与事前检查，减少点击文件链接时的路径错误。

## 浏览器与工具能力

- 浏览器截图可向支持图像输入的模型提供实际画面；不具备视觉能力时明确说明，不再把截图文件路径当成已经看过画面。
- 补齐原生下拉框、受控文件上传与拖放等测试入口；提供可管理的持久浏览器资料，保留已有权限边界。
- 主题工具提前声明能力与版本；异常配置尽量保留有效主题，并记录恢复、修改和删除历史。
- 工作区 Skill 可经确认安装到个人技能库；验证角色可分别声明读取与命令范围；无初始提交的 Builder 工作区和临时检查文件清理得到改进。
- 新增可回放的数值核对能力，数值结论仍须基于实际输入和检查结果，不能由模型自述代替。

## 界面与账号

- 任务运行时默认展示阶段进展，允许手动收起；结束后自动折叠。
- 提高白天模式正文对比度，统一表格表头与内容区底色。
- 账号浮层展示个人邀请码及当前奖励；周额度数字支持超过 100%，额度条仍最多填满。

## 安装与发布边界

- 仅提供 Windows x64 安装版，不新增便携版；旧版本文件继续保留。
- 个人 ChatGPT／Codex 接入继续仅限本地开发，正式安装包中不可用，不接入公共额度池。
- 本次不部署 Web 页面、云端计费或模型网关，不提高最低客户端版本。
- 安装包尚未进行 Windows 数字签名，系统可能提示未知发布者。

# AporiaX 1.0.0-rc.2

2026-09-30 · Windows x64 候选发布版，尚非 1.0.0 正式版。

## 本次更新

- **长对话自动压缩**：主 Agent 接近上下文上限时，用当前选择的模型滚动整理较早对话；完整原文继续保存在本机，可按需回读。后续轮次及恢复可复用已验证的摘要。
- **保留重要上下文**：当前任务要求、明确长期约束、近期完整工具调用组继续保留；摘要失败、取消或收到新指令时，不覆盖原文，不自动切换供应商。摘要属于正常模型调用，会计入所选服务用量；不重放结果未知的付费摘要请求。
- **改善 HTTP 413 恢复**：同时检查上下文 token 和实际请求字节，有限次数缩小重试。不会反复发送同一份超大请求，也不会为了重试绕过 Cloud 防重复扣费保护。
- **Cloud 额度提示更准确**：确认个人或全站额度耗尽后，Cloud 模型不可选；结算后、切回应用及定时刷新可用状态。额度不足与视觉服务不可用分别提示，自带 API 不受这项选择限制影响。
- **本地外部连接与文件权限**：包含此前本地整合的 Control API / MCP 桥接及 Windows 兼容修复。外部连接默认关闭，对接桌面已有工作区；执行控制板中的全局工作区外文件权限默认关闭，开启需明确风险确认，敏感目录与危险操作保护保留。

## 下载与更新

- 安装版：`AporiaX-Setup-1.0.0-rc.2-x64.exe`。
- 便携版：`AporiaX-Portable-1.0.0-rc.2-x64.exe`，退出旧版后手动换包。
- 下载后可用 `SHA256SUMS-1.0.0-rc.2.txt` 校验。
- 本 RC 发布到 GitHub 默认 Latest 更新渠道，便于旧版检查更新；产品仍为 RC。安装版不会在任务运行中强制安装。
- 此次仅发布桌面端，**不更新线上 Web / Cloud 服务、服务器下载镜像或最低客户端版本限制**。使用服务器备用下载入口时，可能仍获取 RC1，请优先使用本次 GitHub Release。

## 边界与注意事项

- 自动摘要不是无限上下文，也不保证逐字无损。单个超大附件、必须保留的内容或不可拆分的供应商状态本身超限时，仍需缩小附件或拆分任务。子 Agent 继续使用已有有界压缩机制。
- 原始历史留在本机，但推理及摘要所需内容仍会发送至用户所选模型服务；没有恢复手机同步、云端项目同步或远程文件上传通道。头像前端继续关闭。
- 本次不启用新许可草案，继续沿用 MIT 及原第三方声明。
- Windows 包仍未配置可信代码签名；不要关闭系统安全防护。升级前建议备份重要项目及应用数据。
- 回归测试与隔离资料启动不等于真实供应商长期任务、干净机器安装和旧用户资料迁移全部验收完成。请反馈版本、脱敏错误和复现步骤，不要发送密钥或完整私人对话库。

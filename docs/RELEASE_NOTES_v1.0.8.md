# AporiaX 1.0.8

Windows x64 · 2026-10-23

这一版重点解决模型长时间没有新输出却一直显示工作中，以及硬件加速被自动关闭后影响浏览器和 3D 预览体验的问题。

## 模型连接与任务等待

- 连续 3 分钟没有新增有效模型数据时，开始恢复检查；不按思考或回答的总时长中断请求。正文、推理、工具参数或实际输出 Token 数持续增长时，不会因为输出较久而触发检查。
- 区分真实输出和网络保活信号，空心跳、重复事件和没有增长的 Token 数不再掩盖停滞。
- 最多自动进行 3 次恢复检查，每次间隔一个完整的无新增数据窗口。第三次后保留仍可用的原连接继续等待，不继续自动重试，也不因这一条件直接把整轮任务判为失败。
- 原连接后来恢复输出时，继续接收原回答并清除等待提示。连接断开时保留已有进度，在 Witness 中说明可继续检查或重新发起；用户停止仍立即生效。
- 不擅自重放文件操作或再次发起可能重复计费的生成。Aporia Cloud 只有明确确认原请求未派发、扣费为零且额度已释放时，才允许安全重试；普通自带 API 不会发送猜测的状态查询或自动重复生成。

## Witness 状态

- 分别展示“恢复检查 1/3”“长时间未收到新的模型数据”“连接已断开”和“已恢复接收模型数据”，不再一直用“正在思考或工作中”解释停滞。
- 第三次检查后明确提示已保留工作、继续等待或由用户重新发起，不显示虚假的完成百分比或因等待本身弹出整轮失败。
- 恢复检查是状态核对，不代表所有模型服务都支持断点续传，也不保证上游一定恢复。

## 硬件加速

- 取消根据 GPU 进程退出而自动禁用硬件加速、写入持久禁用标记的逻辑。
- 忽略旧版遗留的 GPU 禁用标记，不因它在后续启动中持续使用软件渲染；不删除用户的图形缓存或诊断文件。
- 实际加速能力仍取决于显卡、驱动、系统和 Chromium 支持，本更新不承诺所有设备都可使用 GPU。

## 安装与发布边界

- 仅提供 Windows x64 安装版，不新增便携版；1.0.7 及历史安装包继续保留。
- 个人 ChatGPT／Codex 接入继续仅在本地开发版保留，正式安装包中不可用，不接入公共额度池。
- 本次不部署 Web 页面、云端计费或模型网关，不提高最低客户端版本。
- 安装包尚未进行 Windows 数字签名，系统可能提示未知发布者。更新前请从托盘退出旧程序。

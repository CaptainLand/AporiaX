# 侧边聊天 V1

## 使用

重启运行最新源码的 AporiaX 桌面端后，打开空侧栏 → **侧边聊天**；已有标签时，也可以从侧栏右上角 **＋** 打开。旧安装包不会自动包含这些源码修改。

- **关联当前任务**：读取当前任务的公开状态、最初目标与最近用户要求、最近回复、Witness / 工具记录。展开状态栏可直接查看；只查看状态不调用模型。
- **普通聊天**：独立历史，不加载主任务、Understanding、文件或附件内容。
- 底部选择已配置的 Provider / 模型。提问才调用模型，并显示供应商返回的 token 用量；未返回时明确显示“用量未报告”。
- 回答中的记录引用可展开来源；文件或网页链接使用已有工作台打开逻辑，不增加文件授权。
- 回答下方 **发送给主 Agent** 先显示可编辑的确认区。只有点击“确认发送”才调用原有主任务消息入口。
- 停止按钮仅取消侧聊请求；关闭侧聊标签也只取消该侧聊。切换标签或收起侧栏不会停止主任务。
- 任务聊天和普通聊天分别保存历史；清空操作仅清空当前模式，不改动主任务。

## 边界

本版是只读问答助手，不启动第二套 Harness。唯一可调用工具为有上限的公开记录分页查询，不提供命令执行、文件写入、MCP、审批或子 Agent 调用。不会读取隐藏推理。

历史位于应用 userData 下的 side-chats，按工作台范围、任务和聊天模式隔离。每个会话保留最近 100 条消息；单次提问使用有限历史和时间戳快照。应用异常退出后，未完成回答标记为中断，不自动重发模型请求。

提问会将对应模式的历史以及任务模式的公开记录发送给用户选中的模型服务。因此敏感任务应选择合适的 Provider。不主动探测模型或调用收费 API。

状态是可观测事实，不是主 Agent 隐藏思维链；模型回答依据提问时快照，不会后台持续调用模型生成监控总结。多工具查询最多 4 轮，全局最多 2 个并发侧聊请求，防止无界循环。

## 实现位置

- electron/side-chat/context.js：公开上下文投影、稳定引用。
- electron/side-chat/service.js：独立模型调用、只读查询、流式事件、取消和持久化。
- electron/main.js / electron/preload.cjs：仅可信主窗口可调用的 IPC。
- src/workbench/SideChatPane.jsx / SideChatDialog.jsx / side-chat.css：聊天 UI、状态与引用弹窗、模型选择、转交确认。
- 既有 Workbench：空侧栏入口、＋菜单、标签恢复与关闭。

## 2026-09-14 界面收敛

- 顶部重复标题、常驻说明及独立状态行合并为单行工具栏。当前任务 / 普通聊天为分段按钮，状态小标签点击后以应用内弹窗展示详情。
- 正文与输入框对齐主聊天的 14.3px 字号，继承应用字体；用户消息采用靠右、随内容收缩的气泡，回答保留自然段与代码高亮。
- 输入框改为主聊天式圆角布局，随文字增高到 156px，不再显示手动拖拽角；模型和发送按钮保持底部对齐。
- 模型选择由原生 select 改为应用内弹层，复用主聊天模型目录和图标，支持 Provider 分组、搜索、键盘上下选择、Enter 确认、Escape / 点击外部关闭。模型简称与原始 API ID 分离，API 请求仍使用精确 ID。
- 回答的模型、用量和快照时间移至“回答详情”；仅询问进度时的提示词调整为简短回答，详细分析仍可按需请求。

浏览器检查路径：tests/fixtures/side-chat.html。修改前为原生下拉框和常驻状态行；修改后检查搜索筛选、键盘焦点、选中值持久化、侧聊模型不改动主任务模型、输入框字号 / 高度、气泡对齐、浅深色以及窄栏弹层边界。模型测试仍使用模拟服务，不代表已验证真实模型的回答风格。

### 详情弹窗与焦点修复

- Agent 回复 / Witness / 工具引用、任务状态、回答详情、清空历史和转交确认统一使用应用内 dialog；不再插入正文或改变聊天区域的高度。弹窗最多 480px 宽、560px 高，短内容自适应，长内容独立滚动。
- 所有详情均有右上角 ×，支持 Esc、遮罩点击关闭；键盘焦点限制在弹窗内，关闭后返回入口。关闭确认弹窗不会清空历史或发送指令。
- 引用详情复用安全 Markdown 渲染与代码高亮，文件链接继续走工作台原有打开流程，不新增外部文件权限；不执行记录中的 HTML / 脚本。稳定 Markdown 链接组件，防止状态刷新重建链接导致焦点丢失。
- 去掉侧聊输入框的蓝色 focus-within 外圈及全局 textarea 蓝色 outline，保留控件的中性键盘焦点提示；模型选择弹层补充 ×。
- 浏览器回归新增弹窗关闭、焦点恢复、聊天布局不变、草稿保留、源记录安全渲染与文件链接打开、确认取消无副作用，以及浅深色输入框和窄窗口边界检查。不涉及主 Agent 执行流程。

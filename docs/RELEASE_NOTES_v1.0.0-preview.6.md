# AporiaX 1.0.0 Preview 6

本次改善 Cloud 额度用尽前后的任务体验，并暂时隐藏账户头像界面。

- **按实际用量结算**：个人额度不再按单次最大输出提前冻结；已结算余额大于零时可继续请求，不为了塞进余额而缩小模型输出。
- **剩余 5% 时收尾**：在确认周额度大于零且不超过 5% 后，提醒模型保存已有成果、收集正在运行的子任务并交代未完成项；不再启动新子 Agent、排队未启动的 Worker 或追加子任务。不会额外发起一次付费请求。
- **额度耗尽后暂停**：结算到零或负数后阻止后续派发。桌面保存已收到的响应、任务进度和工具结果，额度恢复后可继续，避免重复生成和扣费。
- **恢复保持请求身份**：低额度提示不会改变已发送请求的内容；重启、压缩上下文和并发收据不会重复触发收尾通知。
- **头像界面暂时关闭**：桌面与网页不展示头像或上传入口；保留实现源码和已有数据。账户中心、昵称、额度和登录照常使用。

周额度、全站每日 ¥5 成本保护、并发限制、鉴权和防重复扣费继续保留。自带 API 不受本次 Cloud 收尾规则影响。手机远程同步、电脑文件及项目/对话后台上传通道保持关闭。

实际用量由供应商在响应结束时返回：长请求可能从高于 5% 直接用到负数；已经派发的并发请求也可能继续结算。这里不是逐 token 精确断流，也不保证任务一定能在剩余 5% 内完成。模型调用本身仍会发送本次请求必要的上下文。

安装版通过应用更新入口下载并安装；便携版下载新包替换。二进制未签名，请核对发布来源与 SHA256。Cloud 最低兼容版本暂保留 Preview 4；新的 5% 收尾和耗尽恢复体验需要 Preview 6。

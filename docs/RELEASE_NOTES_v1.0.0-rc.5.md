# AporiaX 1.0.0-rc.5

- 新增专业角色设置：自定义职责、模型、思考强度、预算及受控工具组合；Builder 数量移至设置页。
- 主 Agent 可发现、调度专业角色，按依赖等待或并行执行；角色权限不超过父任务。
- 专业 Agent 面板展示运行状态、结果与用量，支持追加要求和停止。
- 桌面登录、账户中心、Cloud 网关和国内更新镜像统一接入 `https://aporiax.cloud`。
- 旧地址的登录凭据不会自动转发到新域名；升级后可能需要重新登录。

此版本仍是候选版本。Windows 安装包未具备可信代码签名，可能出现系统安全提示。保留原有用户数据；自带 API 配置不受域名迁移影响。

独立网站更新：全站日额度仅预留正在处理的请求，不再预扣待核对请求；实际结算、核对记录和防重复扣费机制保留。

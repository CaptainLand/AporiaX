# AporiaX 1.0.11

Windows x64 · 2026-10-24 · 本地安装包

## 更自由的任务与成员执行

- 保留已放宽的成员能力，按父任务许可、工具选择及任务需要组合命令、浏览器、联网与文件能力，不以角色名称作为能力上限。
- 不恢复固定轮次、累计启动次数或全队自动停工；重复操作按具体动作和不变证据分别处理，不连带关闭其他工具或取消健康成员。
- 已核对接受的 partial 报告可满足明确的下游依赖；报告可用与代码已经集成仍保持区分。
- 独立成员交办不再套用公共控制 API 的默认请求、工具和时长配额，保留用户明确配置的预算及真实授权边界。

## 交付、恢复与文件保护

- 成员清理浏览器、进程、LSP 等资源时的异常不再覆盖已完成报告，单独显示资源清理提示。
- 有命令能力的成员在私有副本中执行，命令产生的文件变更按实际路径取得写租约并核对冲突后集成，避免直接改写共享文件。
- 续写前缀独立保存，恢复原请求回执时保留完整回复，输入压缩或重启后不再只剩最后一段。
- Office、图片等二进制产物支持按字节快照、恢复、集成和回退；结构检查不冒充视觉验收。
- 大文件版本改用绑定工作区、路径及校验和的本地磁盘引用，避免把完整文件内容堆入任务 JSON；回退前仍检查文件是否被后来修改。
- 对齐大项目快照与命令后端的容量，较大恢复元数据可分块保存。

## 长上下文与连续工作

- 委派要求按所选模型的 Token 窗口决定全文或分页投影，不再采用旧的固定字符截断。
- 当前较短原始请求与明确限制保持可见，背景原文可按 ID、偏移继续读取；没有读完的超长明确限制有可定位的范围。
- 保留 1.0.9 的“从已完成处继续”、计划和工具回执恢复、已有文件核对，以及不盲目重放不确定操作的机制。

## 临时测试与链接反馈

- 临时 HTML／HTM 测试页面可登记并通过原有清理工具删除，保留任务归属、工作区、文件身份、硬链接、内容校验与恢复副本保护；类型不支持、内容超限等拒绝原因分别说明。
- 点击回复中的链接失败时改为底部短提示，不再把底层错误拼进正文；本地预览断开时提示服务可能已停止，仍可再次点击重试。

## 安装与验证范围

- 仅生成 Windows x64 安装版及更新校验文件，不生成便携版。更新前请从托盘退出旧版。
- 个人 ChatGPT／Codex 接入继续仅在本地开发开放，安装包禁用；独立 Aporia Account 不包含在本桌面安装包中。
- 本次仅本地打包，不上传、不创建 GitHub Release、不更新官网或云端服务。
- 相关回归通过，新增专项覆盖真实命令、Word 生成与结构检查、SQLite 恢复和文件回退；未调用计费模型，未将模拟检查等同于真实模型长任务或 Docker 实测。
- 安装包未进行 Windows 数字签名，Windows 可能显示未知发布者提示。

# AporiaX 1.0.2

Windows x64 · 2026-10-19

## 界面与交互

- 任务侧栏的文字与用户名降低亮度，选中项保留清晰层次；右侧标签栏增加左侧留白。
- 侧边聊天顶部改为紧凑的小圆角模式模块，浏览器标签移除彩色状态点。
- 工作台六个入口统一为更紧凑的扁平样式，中文界面显示“浏览器”。
- 账户弹窗移除连接标记、模型与设备信息，收紧布局；“账户中心”直接打开应用设置的账户页，顶部展示个人资料。设置中的“网页账户”保留独立入口。
- 图片附件移除文件名遮罩；点击图片在当前界面放大，背景模糊，支持点击缩放、滚轮缩放、拖动和平移，以及 Esc 关闭。

## 团队与个性化

- 团队群聊支持全体成员及多成员提及，各角色使用独立的身份与表达设定。日常问候采用简短回复，减少重复汇报。
- 成员独立任务经用户确认后启动，使用独立的执行与记录空间；结果可在相应会话中报告，不加入主任务的 Witness 与执行记录。
- 个性化回到基础配色与背景功能，高级组件覆盖和整面板渐变不再生效；保留旧配置数据以兼容已有资料。

## 安装与数据

- 保持 1.0.1 的原目录覆盖安装方式，不增加跨目录整理或自动清除旧副本流程。
- 本版按当前本地工作副本构建。官网社区欢迎页和账号法律文本草案不在桌面软件中启用。
- Setup 与 Portable 分别提供 Windows x64 文件；便携版可手动更换程序文件，重要资料请保留备份。

## English

Version 1.0.2 refines sidebar typography, workbench shortcuts, account controls, browser tabs, and the side-chat toolbar. The account popover now opens the in-app account profile. Image viewing uses an immersive, zoomable and draggable overlay. Team meetings support multiple mentions and concise role-specific responses; confirmed member jobs retain their own execution records outside the main task. Personalization returns to the basic color and background controls. The existing single-directory overwrite installer flow is retained.

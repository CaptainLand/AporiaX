# AporiaX 1.0.0-rc.5.2

- 安装器增加旧更新器兼容。旧客户端未传入安装目录时，核对当前产品的安装及卸载记录；唯一有效目录继续更新，多份有效安装则要求用户明确选择，不默认落到 C 盘。
- 覆盖前同步目标安装目录与卸载路径，避免对另一份安装执行卸载；更新自定义目录时不追加额外的 AporiaX 子目录。
- 保留 RC5.1 从当前可执行文件固定更新目标、修复已有快捷方式和任务运行中禁止安装的保护。
- 无法可靠识别目标、静默更新遇到目录歧义，或全用户更新可能删除另一份独立用户安装时，安全中止。取消或安装失败恢复本次调整的目录记录；这不是断电或写盘失败后的完整文件回滚保证。

更新提示：已经下载的旧 RC5.1 安装包不会自动获得本次修复。请刷新检查更新并取得 RC5.2；若旧客户端仍停留在旧包的“已下载”状态，可从官网取得 RC5.2 安装包，确认原安装目录后运行。不替换已发布的 RC5.1 文件。

此版本仍为候选版，Windows 安装包尚无可信代码签名。便携版仍需手动换包。本次不修改模型调用、Cloud 扣费或用户对话数据。

# 手机同步通道移除记录

日期：2026-09-24。范围：当前桌面活动源码、账户 IPC、前端及本地 Windows 验证包。没有发布 GitHub Release，也没有替换其他用户已安装的版本。

## 已移除

- 后台整理并同步本地项目、完整对话和任务快照的前端逻辑。
- 手机远程命令轮询、领取、确认和执行链路。
- 电脑目录/文件浏览、读取及向手机中转上传的账户模块。
- 上述功能的 preload API、主进程 IPC、账户运行时方法，以及账户菜单控件和样式。
- 原来的功能开关，避免仅靠隐藏 UI 或服务端 capability 来关闭通道。

已删除 `src/account/remote-sync.js`、`electron/account/remote-file-broker.js`、`electron/account/remote-command-inbox.js`。Cloud 模型网关接口另有固定路径白名单，不能作为任意账户上传接口使用。

## 保留及清理边界

- 本地任务、对话历史、项目文件和登录凭据未删除；普通登录、额度、模型推理、账户中心继续保留。
- 新版账户模块启动时，按固定文件名移除旧手机文件授权配置和远程命令缓存数据库（包含其 WAL/SHM/journal）。不读取内容、不递归删除目录。旧程序占用导致失败时会警告，之后启动重试。
- 未跟踪的手机原型移至本地 `.tmp/privacy-channel-removal-backup/aporiax-mobile`，属于可恢复归档，已加入 Git 忽略且不在桌面打包范围。活动 `aporiax-mobile` 仅留退役说明，旧原型源码/APK不作为新版本发布。
- Git 历史、旧安装包和本地归档没有被清空；这不等于旧客户端已经更新。分发时需使用重新构建并验证的新包。

## 实测

- 隐私回归：生产源码无同步接口及实现，preload 账户 API 仅保留 get/signIn/openCenter/refresh/signOut。
- 账户请求测试：仅预期账户/设备/额度等请求，私有本地任务哨兵内容没有进入请求；旧远程能力和旧开启标记不能恢复同步。
- Cloud 兼容性 16/16；外层恢复 12/12；账户中心、账户 UI、模型初次配置、流式性能及本地历史持久化测试通过。
- 浏览器：浅色/深色账户菜单无手机入口，无远程轮询调用，账户中心及退出登录正常；截图已检查。
- `npm run build` 与本地 Windows unpacked 打包通过；ASAR 已检查无退役模块/接口，218 个 electron/shared/dist 文件逐字节等同当前源码及构建产物。
- 发布校验脚本已增加退役模块及代码签名拦截，避免后续包误带回旧通道。

验证包：`.tmp/privacy-desktop-package/win-unpacked/AporiaX.exe`。仅用于本地验证，不是已经上线的新版本。没有执行真实付费模型请求或新用户注册。

## 当前服务器只读核验

- 公网 `/api/remote/desktop/tasks` 与 `/api/remote/mobile/tasks` 返回 404；API 健康检查正常。
- 当前服务端实现对旧远程请求保留拒绝处理，不开放文件/任务同步功能。
- 当前预览数据库 public schema 未发现远程项目、对话或文件存储表；`devices.remote_enabled = true` 的记录数为 0。
- 本次未删除云端账户、额度或模型账单。上述核验针对当前部署，不是对所有历史备份/旧环境的全量取证。

## 不应误导用户的数据承诺

移除的是“为手机访问而后台同步电脑数据”的通道，不是模型推理本身。选择 Aporia Cloud 或第三方 API 时，提示词、相关对话、工具返回的文件片段及明确提供的附件仍可能发往所选模型；Aporia Cloud 请求会经过模型网关。用户授权的联网工具、MCP 和 Git 推送也是独立的数据出口。

README（中英文）及 SECURITY 已同步此边界，不能对外宣称“完全离线”或“任何文件/对话都不会离开电脑”。

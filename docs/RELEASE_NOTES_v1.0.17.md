# AporiaX 1.0.17

- Aporia Cloud 遇到鉴权失败时自动尝试刷新凭证，再按原请求核对状态。已完成的结果优先取回；无法安全确认时保留进度，不盲目重发。Witness 会显示刷新与核对过程。
- 「自动执行」与「一律通过」共用常规构建、验证、打包和本轮 HTML 预览交互的审批规则。需要额外授权时，前者询问，后者跳过并记录原因。
- 工作区内的 ZIP/OSK 打包不再被误判为任意脚本；显式覆盖时保留旧包，明确没写入的失败不会阻塞重试。
- 安全副本模式下，后台预览使用临时副本且不回写；Docker 隔离不会将 Git 等宿主命令静默放回本机运行。

本版提供 Windows x64 安装包。

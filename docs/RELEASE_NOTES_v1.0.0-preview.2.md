# AporiaX 1.0.0 Preview v2

版本号：`1.0.0-preview.2`。Windows x64 安装版和便携版；本次只在本地打包，未自动发布 GitHub。

## 桌面端

- 汇入前序已完成的 Cloud v1 适配、外层任务恢复请求身份、端点隔离和能力检查。
- Cloud Flash 与原生图片输入能力按服务端状态展示，未配置公网 Cloud 时仍可使用自己的 API。
- 包含教程入口，以及已有的任务暂停恢复、多 Agent 执行记录、项目知识和工作区优化。
- 不内置 localhost 私有隧道地址，也不打包 API Key、SMTP、SSH 密钥或个人任务数据。

## 配套 Web

- 区分实际可用、暂时预占、已使用和未确认用量。
- 模型目录不再暗示设备必然可调用；计费状态来自后端。
- 未实现的远程控制禁用；设备移除、会话撤销、资料保存有失败反馈。
- 网络/服务不可用提供重试，不直接当作会话过期；演示模式与真实授权分离，公开构建默认关闭。
- 首页介绍更新，保留教程和 GitHub Latest 下载入口。

## 使用边界

当前备案未完成，公网 Cloud 地址与 HTTPS 未在本次启用。私有预览仍通过 SSH 隧道。
源码工作区运行 `npm run start:cloud-preview`；普通安装包可使用 BYOK。
Web 是独立项目，需要另行发布才能改变线上站点。
任务恢复不意味着任意进程、断电或外部副作用都能无损自动重放。

# AporiaX 1.0.12

## 界面与使用体验

- 用户及 Agent 伙伴头像统一为简洁的纯色色块，角色名称、职责和原有头像选择保持不变。
- 改进对话排版与表格显示，表头优先保持完整，较窄窗口可以横向查看表格。
- 调整对话文字与页面细节，方便阅读。
- Agent 工位改为实验功能：首次在当前任务打开时需主动开启；重启后再次确认，不开启也不影响任务运行。
- 图片附件支持横向查看，可选择更多图片；具体模型或服务仍可能限制单次请求容量。

## 安装说明

- 仅提供 Windows x64 安装版，更新前请从系统托盘退出旧版。
- 个人 ChatGPT／Codex 账号接入仍仅供本地开发使用，不在公开安装版启用。
- 安装包未进行 Windows 数字签名，Windows 可能提示未知发布者。

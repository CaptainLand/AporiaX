# 桌面社区插件市场

设置入口在「权限与审批」下方。桌面只在登录后拉取目录，沿用账号的社区规则确认状态。所有已公开资源可浏览；只有作者允许下载的版本可以添加。

添加时重新检查公开版本和 SHA-256，用户确认后，先通过现有 API 写入私有社区仓库，再走桌面接收校验并保存到本机。仓库导入完成而本机保存未完成时，可重试同一项；不会因重试重复创建云端副本。MCP 和子 Agent 不随导入启用，皮肤不自动应用，Skill 不自动触发。

桌面添加前会查找本机相同类型、同上传快照的原始配置，以及当前账号已接收且未改动的相同内容。已有匹配不重复保存；同名但快照不同不当作重复。对源于同一投稿同一版本的已接收副本，仍保留本机后续的编辑。

## 从桌面投稿

「刷新」旁的「上传插件」只列出本机可分享的配置。预览的是经过脱敏处理的上传内容，提交前再次检查配置没有变化。作者需明确同意公开，并可单独决定是否允许下载。桌面与网页版使用同一个投稿 API 和账号额度，新投稿每周限三次，按北京时间周一零点重置；显示的剩余次数来自服务端。当前设置页内重试未确认结果的同一投稿时复用提交键，不重复消耗额度。

投稿按资源类型与实际上传内容的 SHA-256 查重，不以名称判断。桌面在预览及新提交时查自己的投稿记录与公开市场。Cloud 更新后，网页版和桌面都由同一服务端事务拦截重复，拒绝不扣额度；同一个已受理的幂等键仍可查询结果。不会因为发现重复自动下架现有记录。

「我的投稿」显示当前账号自己的记录，用投稿时间与短编号区分同名条目。确认下架后停止公开展示和新增导入，已保存副本不变。尚未公开的待审或退回稿可撤回；下架和撤回均不会退回投稿额度。

## 下载次数和兼容性

计数口径是社区版本成功导入私有仓库的次数（包括现有网页端操作），不是卡片点击次数，也不保证此后本地保存成功。相同版本已在仓库时重复请求不加计数。撤下后仍保留累计值；用户从仓库移除后重新导入属于一次新导入。

Cloud 变更位于 `.tmp/aporiax-cloud-server-preview` 的社区实现中。升级服务时，先执行增量迁移 `packages/database/migrations/20261126-community-download-count.sql`，再切换新版 API。迁移以已有的仓库副本回填历史下限：已经移除的旧副本和被覆盖的旧版本无法从现有记录恢复。迁移不修改社区规则或下载许可。旧 API 未返回计数时，桌面按发布时间展示，不把未知计数显示为零。

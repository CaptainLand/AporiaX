# AporiaX 0.9.7

日期：2026-09-16。Windows x64 Preview。

## 本版更新

### 本地 OCR

- 从输入栏 OCR 按钮、图片/PDF 附件或侧栏文件预览进入。
- 支持 PNG/JPEG/WebP、中英文图片、扫描 PDF 和混合 PDF；有文字层的页复用文字，无正文的页识别。
- 可选择页码、语言和旋转方向，查看进度、取消、对照原页，复制/另存文本或加入对话附件。加入附件不会自动发送。
- 逐页保留来源与 OCR 置信度；空白/失败/截断结果不冒充全部成功。文字层不伪造置信度。
- 首次明确点击下载约 4.7 MB 中英文资源，此后本地识别，不上传文档。模型文件固定版本并校验 SHA-256。
- 单文件 16 MiB、一次最多 20 页（页码 1–240）、同时一项识别；本次会话最近 3 个成功结果可复用。

不保证手写、复杂公式、竖排、表格排版还原；识别结果请核对原页。

### Git 冲突处理与 PR

- Git 侧栏点击冲突文件，对比共同基线、当前分支和合入分支，编辑结果。
- “保存合并结果”保留原件备份；确认后再点“标记已解决并暂存”，最后核对暂存列表并提交。不会自动推送。
- 保存时核对文件/index 是否变化；阻止活跃任务与未保存侧栏草稿竞写。原件恢复目录位于应用数据下 `git-conflict-recovery`，保存后显示具体位置。
- 首版支持 1 MiB 内 UTF-8 文本的普通 merge 冲突；二进制、删除/修改、重命名等使用终端。rebase/cherry-pick/revert 显示状态并提供终端入口，不自动续跑。
- 新增 PR 页：通过已安装且登录的 `gh` 查询选定 github.com 仓库、当前分支的 PR 和检查状态，并打开网页。只读，不创建/合并 PR；区分无 PR、未登录、无权限、离线与限流。

### Builder 并发与可靠性

- 并发选择：**0 / 1 / 2 / 3 / 4 / 6，默认 2**。0 禁用，1 串行；其余按任务需要委派，不自动开满。
- 并发数量不再等于整个任务累计只能创建几个 Builder；超出的工作排队。用户显式设置的累计预算仍生效。
- 输入栏显示运行/排队数量。预算事件走统一事件序号，避免破坏任务事件回放。
- 创建工作树前预检范围与快照预算；范围外大脏文件采用流式哈希保护，不再被可写快照的单文件额度误挡。
- 修复非 UTF-8（如 GBK）Builder 检查点的有损恢复；中断恢复、合并与回滚保留字节，恢复时保留原资源配置。

快照资源通过启动 AporiaX 前的环境变量配置，单位为字节；配置矛盾/超硬上限会拒绝，不静默改值：

| 环境变量 | 默认 | 硬上限 |
| --- | ---: | ---: |
| `APORIAX_BUILDER_MAX_FILES` | 3000 文件 | 10000 文件 |
| `APORIAX_BUILDER_MAX_BYTES` | 32,000,000 | 64,000,000 |
| `APORIAX_BUILDER_MAX_FILE_BYTES` | 8,000,000 | 16,000,000 |

高并发会增加磁盘、内存和 API 开销。六工作树合成探针通过，不代表任意大仓库都适合并发 6；建议保持默认 2，遇到不重叠的大任务再提高。

## 验证

六组 0.9.7 专项测试、实际 Electron/ASAR OCR、真实 Edge 浅/深主题与窄栏验证通过；既有长任务回归 **36/36** 通过，运行时和相关 Git/附件回归通过。生产构建通过，仍存在主 JS chunk 较大的告警。

执行 `npm start` 可查看本地开发版；新功能专项验证命令为 `npm run test:0.9.7`。

## 依赖与许可

- [Tesseract.js 7.0.0](https://github.com/naptha/tesseract.js)：Apache-2.0，本地 WASM OCR。
- [Tesseract.js 语言数据](https://github.com/naptha/tessdata)：固定 `@tesseract.js-data/eng` 与 `chi_sim` 的 1.0.0 `4.0.0_best_int` 资源；两个 npm 资源包均标注 MIT。正式分发前仍需连同模型上游声明核对并保留许可，不将资源包许可等同于完整上游审查。
- [@napi-rs/canvas 0.1.100](https://github.com/Brooooooklyn/canvas)：MIT，本地图片/PDF 页面渲染。
- 复用 [PDF.js](https://github.com/mozilla/pdf.js)：Apache-2.0。

## 与 1.0 的关系

本版完成 OCR、Git 和 Builder 的这一批升级，不是 1.0 发布就绪声明。历史审查 N1–N3 的任务保存/迁移可靠性问题仍待修复；本批修复的是 N4 Builder 字节级恢复。发布前仍需实际安装包、干净设备、升级恢复及签名等验收。

# AporiaX 0.9.5

Windows x64 Preview 更新：修复工具消息与任务重试，并同步此前的 MCP / Skill 生态和可靠性改进。

- [便携版](https://github.com/CaptainLand/AporiaX/releases/download/v0.9.5/AporiaX-Portable-0.9.5-x64.exe)
- [SHA-256 校验文件](https://github.com/CaptainLand/AporiaX/releases/download/v0.9.5/SHA256SUMS-0.9.5.txt)

## 同步的前序改进

- MCP / Skill 在线发现、来源/许可/依赖查看、安装或连接后的可用性检查；移除无实际用途的推荐占位条目。
- 纳入带来源和许可证的 Word 文档、文档主题和调试 Skill 资源；需要的运行时、依赖与账号仍须配置。
- 同步长任务上下文、持久化恢复、Builder 合并、审批与远程命令等可靠性改进。

## 修复

- 修复读取外部目录时工具回执缺少 `modelResult`，导致模型请求缺少 `messages[].content` 的问题。
- 主循环串行、并行工具执行增加返回结构检查；模型调用边界提前拒绝不合法消息，不发送注定失败的请求。
- 恢复旧检查点时，缺失的工具结果标记为“结果未知”，保留有效证据，不伪造执行成功、不自动重放旧操作。
- 修复重试时后台运行状态查询失败可能中断新一轮任务的问题；兼容分支同样遵守中断限制。
- Witness 仅跟随最新可见轮次，不再回退到已被重试替代的失败记录。
- 同一对话继续工作后，旧失败/受阻/停止记录折叠为历史；运行期间禁止点击历史重试。
- 失败页展示已保存文件的可点击链接，排除删除/回退文件，明确任务未完成、不能据此认定验证通过；原始错误可展开查看。

## 回归验证入口

`npm run test:run-reliability`

覆盖工具回执、实际循环单条/批量目录读取与并行文件读取、旧消息恢复、重试状态保护、失败/继续/重试/新任务界面、文件链接和 Witness 隔离。

`node tests/runtime-context-recovery.mjs` 验证包含缺失回执的检查点恢复；不调用真实模型、不改动真实用户任务。

发布前本地 17 组相关回归测试通过；180 个包内源码/资源与构建输入一致，22 个终端原生文件解包检查及安装包更新哈希检查通过。这不代表覆盖所有模型服务与用户环境。

## 使用

退出旧版后运行 0.9.5 安装版或便携版。旧失败记录仍保留；恢复时会对缺失工具结果按未知处理，模型需要重新检查实际状态。后台服务、网络及模型服务自身不可用仍可能导致任务失败，本版不将这种失败伪装成成功。

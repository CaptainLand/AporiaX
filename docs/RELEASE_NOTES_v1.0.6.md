# AporiaX 1.0.6

Windows x64 · 2026-10-22

这一版主要让查资料、读文档和查看任务结果更顺手：AporiaX 多了两种联网工具，Markdown 阅读区换上更轻的排版，回复和执行进展也更清楚了。

## 联网工具

- 新增广搜索和网页正文读取，可与现有浏览器配合使用，由 AporiaX 按任务选择。
- 接入现有工具目录、权限和执行记录；搜索结果与网页内容作为外部资料处理，不作为指令执行。
- 读取网页包含地址、重定向、响应大小和超时检查；本地代理 DNS 环境下可使用带来源提示的远程正文提取。
- 搜索使用 Exa 服务，关键词会发送给搜索服务；匿名访问可能受到频率或服务额度限制，遇到限制时仍可使用原有浏览器。

## 更统一的 Markdown 阅读体验

- 阅读区沿用 AporiaX 的字体与配色，缩小标题、收紧段落和列表间距，暗色正文不再过亮。
- 分割线和引用线更低调，表格去掉整圈网格边框，改用轻量的行分隔与表头底色。
- 普通表格铺满阅读区，宽表格和长代码保留内部滚动；标题跳转、链接、图片、源码与编辑功能保持不变。

## 对话与回退

- 补充回复使用紧贴正文的箭头展开，文件修改结果一起收进展开区；没有补充内容时不显示空入口。
- 移除自动追加的未运行检查套话；实际失败和影响使用的问题仍明确提醒。
- 收紧列表间距、降低暗色正文亮度，阶段进展改用可一次展开全部内容的低调渐隐细线。
- 时间和 Anchor 改为无描边样式；回退预览显示回退将删除或恢复的内容，而非本轮正向修改。
- 精简重复交付提示，减少小上下文模型的固定开销；上下文预算、权限与安全边界保持不变。

## Witness

- 有计划时显示实际完成步骤数，没有计划时显示当前活动，不再用工具次数或阶段猜测百分比。
- 仅明确完成的任务显示 100%；部分完成、受阻、等待补充、暂停、失败和停止分别显示真实状态。

## 安装包

- 本版仅构建 Windows x64 安装版，不构建便携版。
- 个人 ChatGPT／Codex 接入继续仅供本地开发使用，正式安装包中保持不可用。
- 不修改云端计费、模型网关或公共额度池。
- 安装包尚未进行 Windows 数字签名，系统可能提示未知发布者。

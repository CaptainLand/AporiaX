# AporiaX 1.0.0-rc.1

日期：2026-09-26。Windows x64 候选发布版，不是 1.0.0 正式版。

## 交付范围

- 基于当前本地桌面源码冻结功能，生成安装版和便携版；不新增大型功能。
- 本次发布安装版和便携版到 GitHub 默认更新通道，并同步内测网站下载镜像；版本仍为 RC，不是 1.0.0 正式版。最低客户端版本不提高。
- 配套 Web 的全站日额度复用周额度动态条，只显示百分比。网页日额度接口不再返回金额字段，Cloud 计费、每日上限、账户数据及安全配置不变。
- 继续使用现有 HTTPS 内测 Cloud 端点；Cloud 仍为 Beta，不承诺它随桌面 RC 一同完成正式运营验收。
- RC 继续沿用现有 MIT。新许可草案不在本次启用，留到正式版经最终审核后发布；第三方许可和声明保留。

## 本次重点

1. **扩展调用闭环**：已安装 Skill 搜索、完整说明和引用资源读取；MCP 工具发现、错误反馈、运行中显式接入及恢复。
2. **安全恢复**：MCP 选中身份写入本地检查点，恢复时按当前可信配置重新解析；删除或禁用的服务不会被旧检查点复活。未知结果的业务操作不因重连自动重放。
3. **网页引用冻结**：`@browser` 引用按用户消息保存本地快照，重试不读取后来切换的页面；缺失/损坏时需在新消息中重新引用。
4. **候选加载隔离**：显式 `@skill` 不扫描文件，也不等待 MCP；各候选源独立返回，保留中文路径、输入法、新文件和陈旧结果防护。
5. **小上下文兼容**：修正 32K 模型的上下文预留，避免初始系统与工具开销挤占过多可用窗口；用户要求和硬超限保护不变。
6. **承接已落地能力**：有限次数的澄清提问、接近额度耗尽时的收尾、启动检查更新及没有新版本时隐藏侧栏入口。手机同步/远程文件通道仍保持移除，头像前端仍关闭。

详细修复与源码回归证据见 [整体修复记录](overall-repair-2026-09-26.md) 和 [扩展闭环记录](extensions-loop-repair-2026-09-26.md)。RC 本次打包验证结果单独记录于 [RC 验证清单](releases/1.0.0-rc.1-validation.md)，不将历史通过数冒充本次结果。

## 安装与测试

- `AporiaX-Setup-1.0.0-rc.1-x64.exe`：安装版。
- `AporiaX-Portable-1.0.0-rc.1-x64.exe`：便携版。
- `SHA256SUMS-1.0.0-rc.1.txt`：下载/复制后核对校验值。
- 请正常退出旧版再启动候选包；先备份重要项目及应用数据。便携版不等于独立账户或独立用户数据目录。
- 先验证登录/自带 API、一个简单文件任务、Skill/MCP、断网恢复和升级后的历史记录。反馈时带版本、复现步骤和脱敏错误，不要发送密钥、完整对话库或私人项目。
- 安装版启动时检查更新，发现新版后显示左下角入口；便携版从 Release 或网站下载后手动换包。不会强制安装正在运行的客户端。

## 明确限制

- 安装包未配置可信代码签名；不要关闭系统防护或忽略证书错误。
- 本地测试不等于干净机器、异机默认浏览器登录或长期真实模型任务已验收。
- 真实硬件睡眠/网络切换、旧版数据升级、备份恢复和外部用户试用仍需要 RC 阶段记录。
- 应用已收到的状态可以保存，不包括模型供应商尚未返回的内部计算。未知结果应核对，不盲目重试可能产生副作用的操作。
- 本地优先不等于零外发：模型推理所需上下文与明确引用的内容仍会发送到所选模型服务；这不是恢复手机同步或整库上传。
- Safe 是工作区副本保护，不是操作系统沙箱；Docker 不可用时 Isolated 不应降级为宿主执行。

正式版前只修发布阻断问题、完成实机与长稳验收、统一发行文档和最终许可，不继续扩大功能范围。

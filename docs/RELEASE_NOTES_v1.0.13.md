# AporiaX 1.0.13

- 主 Agent 按需加载工具和会话历史，短任务不用再携带整套工具说明。子 Agent 优先接收当前交办和相关约束，其他历史可按需读取。
- Agent 主动展示 HTML 时打开浏览器预览，Markdown 打开阅读视图；普通源码留在回复的文件链接里，不自动打开侧栏。
- 右侧栏默认采用主界面约 70%、侧栏约 30% 的布局。窄窗口优先保留主界面空间，手动调整过的宽度不会被覆盖。
- Witness 的 ↑ 只显示未命中缓存的输入 Token。总用量、输出和缓存命中率仍然可见，不影响计费；没有缓存明细时不推算未命中量。
- 修复 Cloud 续跑：恢复后的请求内容有变化时，先核对上次请求，能取回的回复不再重新生成。

## 安装说明

- 仅提供 Windows x64 安装版。覆盖安装前请从系统托盘退出旧版。
- 个人 ChatGPT／Codex 账号接入仍只在本地开发版可用。
- 安装包未进行 Windows 数字签名，系统可能提示未知发布者。

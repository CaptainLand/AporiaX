# AporiaX 1.0.0 Preview v4

这是预览测试版本，并非 1.0.0 正式稳定版；作为 Latest 发布，让现有桌面用户能发现更新。

- 每次启动检查更新；网络恢复或回到窗口时重试，失败不会误报“已是最新”。
- 左下角常驻更新入口：新版提示、下载进度、重启安装；关闭提醒后仍可找到更新。
- 修复 Preview 与正式版排序和更新频道选择；GitHub 不可达时尝试服务方 HTTPS 镜像。
- Cloud 启用最低支持版本：旧桌面需升级到 Preview v4 才能登录和调用模型，网页登录不受影响。本地文件和自带 API 不受此限制。
- 模型遇到关键歧义可申请用户回答：选项或自由填写，每项原始任务最多两次，重复追问受限；右下角提醒，未回答时暂停等待。
- 移除手机远程文件／对话／项目同步通道。Cloud 正常模型请求仍会发送完成任务所需的输入，不能理解为任何内容都不离开电脑。

安装版：下载后点击重启安装；有活动任务时阻止安装。便携版：下载新版后手动替换，不会静默覆盖当前程序。

早期独立 AporiaX Beta 包曾禁用自动更新，需手动下载这次新版；其独立用户数据目录不会自动合并。

Windows x64 安装包未做代码签名。请仅从本项目 Release 或维护者 HTTPS 网站下载并核对 SHA256，不要关闭系统防护。

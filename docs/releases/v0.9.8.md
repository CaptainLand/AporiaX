# AporiaX 0.9.8 — Durable history and writes / 历史与写入可靠性

## 中文

相对 0.9.7 的可靠性跟进。请先退出旧版再更新。

- **任务历史**：部分迁移可重试并保留原件；损坏记录不挡住健康历史；删除显式归档。
- **可恢复写入**：普通文件、补丁和 Office 与 Builder 合并共用备份提交。
- **Builder / Safe**：委派快照与合并；Kernel 并发 6；Safe 在同一任务成功命令之间保留私有依赖。
- **OCR**：子进程识别、混合页与强制 OCR；输入栏和侧栏按钮暂时隐藏。
- **IPC / MCP**：主窗口来源检查；超时取消传到 MCP，不把远端副作用说成已撤销。

Windows x64 安装版与便携版随 `latest.yml`、blockmap 和 SHA-256 发布。当前包未代码签名。

## English

Reliability follow-up after 0.9.7. Quit the previous build before updating.

- Durable task history, recoverable workspace writes, delegated Builder merge, and task-local Safe dependencies.
- OCR runs in a child process; composer and sidebar OCR buttons are hidden for now.
- Trusted IPC origin checks; MCP cancel/timeout without claiming remote work was undone.

Windows binaries are unsigned; verify the published SHA-256 checksums.

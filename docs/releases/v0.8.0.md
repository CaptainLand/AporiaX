# AporiaX 0.8.0 — Same-screen Workbench / 同屏工作台

## 中文

### 核心更新

- **同屏工作台**：右侧栏在同一屏幕打开 Route、Workspace、Understanding、文件、Browser、用户终端和 Agent 进程日志。Agent 用的 Browser 与用户是同一块原生视图，不再另开一套。
- **Agent 决定何时打开**：写文件或跑命令不会自动弹出侧栏。需要给用户看时，Agent 调用 `present_to_user`。最终回答里的 Markdown 链接不会打开侧栏。
- **重启不再闪退**：退出后再打开，不会继续对已经不存在的 Browser / 终端 id 发布局请求。过期标签会被清掉，主进程对缺失资源不再抛错。
- **GPU 崩溃保活**：显卡进程连续崩溃时不再把整个窗口杀掉。崩过之后下次启动会清 GPU 缓存并关闭硬件加速。欢迎页着色器降到 48fps，并错开加载。
- **审批通知**：角落通知改为 10 秒；去掉异常的系统阴影。应用内审批卡片仍在，点了立刻关掉。

### 使用与限制

- Windows x64：Setup 安装版和 Portable 便携版。请先退出旧版再更新。
- 数据仍在 `%AppData%\Roaming\AporiaX`。
- Browser / 用户终端 / 进程会话不会跨完整退出恢复；文件、Route 等标签会记住。
- 未部署或重启 Cloud。
- 保留 0.7.5 及更早安装包，不覆盖旧附件。

### 验证

工作台状态与 present 冒烟、GPU 保活源码检查、审批 toast 冒烟已通过。`vite build` 随 `dist:win` 执行。测试使用模拟模型流，不调用付费 API。

## English

- Right sidebar hosts Route, Workspace, Understanding, files, Browser, user terminals, and Agent process logs on the same screen. Agent and user share one native Browser view.
- Opening sidebar content is Agent-led via `present_to_user`. Writing a file or running a command does not auto-open tabs. Markdown links in the final answer do not open the sidebar.
- Relaunch no longer restores dead Browser/terminal sessions or crash-loops on stale layout ids. Missing resources return quietly and expired tabs are dropped.
- Three GPU process crashes no longer quit the window. A later launch can clear GPU caches and disable hardware acceleration. Welcome shaders run at 48 fps and mount in sequence.
- Approval corner toasts last 10 seconds and no longer clip a native window shadow. The in-app approval card remains until answered.

Windows x64 installer and portable packages are provided. Quit the previous build before updating. Cloud was not deployed in this release. Existing 0.7.5 assets remain unchanged.

Validated with workbench state/present smokes, GPU-guard source checks, and approval-toast smokes, plus the production renderer build inside `dist:win`. Tests use mock providers and do not call billed APIs.

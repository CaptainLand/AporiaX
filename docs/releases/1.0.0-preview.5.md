# AporiaX 1.0.0 Preview 5

本次重点改善 Aporia Cloud 模型调用，并补齐跨端账户头像。

- Cloud 与直连 API 对齐思考模式和输出预算；保留 DeepSeek 工具续接所需状态。
- 长度截断后进行一次有边界的恢复，未完成的工具调用不会执行；已产生的用量仍按实际结算。
- 多 Agent 按 Cloud 可用并发排队，执行记录明确显示等待与开始，不再把排队误显示为思考。
- 区分上下文过长、额度不足、预占容量不足和结果待核对；结果不明时仍禁止重复付费生成。
- 启动自动检查更新，无新版本时隐藏左下角入口；设置中的手动检查保留。
- 网页账户中心支持选择、预览、保存和移除头像；桌面账户栏及菜单同步显示，返回窗口时刷新。

周额度、全站每日费用保护、鉴权和安全边界保留。头像只保存用户主动选择的缩略图；不恢复电脑文件、项目、对话的后台同步。Cloud 模型调用仍需传输本次请求的必要上下文给网关和模型服务商。

安装版可检查、下载并重启安装；便携版跳转下载新包。Preview.4 暂时仍可登录使用。

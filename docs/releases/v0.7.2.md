# AporiaX 0.7.2 — Reliable Recovery & Live Guidance / 可靠恢复与即时插话

## 中文

### 核心更新

- **任务恢复**：统一 Core 任务生命周期、SQLite 事件存储、持久化检查点与操作回执。异常停止后依据已保存状态恢复；不确定或已完成的副作用重放需重新批准。
- **验证可靠性**：验证结果绑定当前文件版本；读取证据检查内容哈希、分段覆盖与修改区域；损坏、截断和不完整的模型流不再按成功结果执行。
- **减少无效循环**：自检重复无进展与环境阻塞明确结束并保留工作，避免盲目重试。持久化失败时明确报告并停止执行。
- **Harness 效率补丁**：上下文压缩替换旧摘要并遵守预算；Main 独立工作可与 Builder 并行，依赖完成即调度；可选探索不阻塞交付。Verify 默认直接执行验证命令并复用当前版本证据；流式事件批量持久化、Anchor 延迟扫描与缓存、通用重复工具保护减少额外开销。审批、恢复与必要审查不跳过，已发生的子任务用量保留。
- **运行中插话**：取消主模型正在生成的请求，带上新要求重新生成。已经开始的工具正常完成，尚未开始的操作跳过；已有输出保留，新回复跟在插话下面。
- **文件交付操作**：Markdown 文件链接支持中文、空格、绝对/工作区相对路径与行号；提供打开、另存为、文件夹定位、其他应用/IDE 打开、复制路径和文件名。可执行文件需确认，缺失文件明确报错。
- **Desktop 远程入口**：合入已有任务同步与只读文件传输控制，文件内容传输需逐文件确认。未发布或修改 Mobile/Web/Cloud 服务。

### 使用与限制

- Windows x64：Setup 安装版和 Portable 便携版。请退出旧版后更新；建议先备份重要任务数据。
- 恢复不能复活断电前的模型请求或系统进程；插话取消不会退回已经产生的 API 费用。
- 插话不强行中断正在执行的工具、子 Agent、审批或收尾步骤。
- 文件默认由系统关联程序打开；IDE 首次操作需手动选程序。本版本不提供内嵌文件预览或自动记住 IDE。
- Cloud 登录及远程功能仍依赖服务可达性；此版未验证生产账号的端到端登录。
- 保留 0.7.1 历史版本，不覆盖旧附件。

### 验证

主循环插话集成、SQLite 恢复、可靠性 P1、Provider 流、消息排序、实际 React 浏览器交互、Electron 文件菜单处理及生产构建已验证。测试使用模拟模型流，不调用付费 API；原生程序启动、剪贴板和系统对话框在自动化中模拟，另存为使用真实临时文件。

## English

- Unified Core task lifecycle, SQLite event storage, durable checkpoints and operation receipts. Recovery requires fresh approval before uncertain or duplicate side effects.
- File-version-bound verification, content-hash/range-based read evidence, strict provider stream completion, and explicit no-progress/environment-blocked exits.
- Efficiency follow-up: bounded checkpoint replacement, optional scoped Main work concurrent with Builders, dependency-driven scheduling, optional background cancellation with completed-round usage retained, deterministic version-bound Verify, transactional stream-event batching, lazy/cached Anchor scans and a generic repeated-tool guard. Approval and required review gates remain enforced.
- Live guidance cancels current main-model inference without aborting the task. In-flight tools finish; not-yet-started operations are skipped. Pre-guidance output stays visible and subsequent replies follow the new user message.
- Actionable file links: Open, Save as, Show in folder, Open in another app / IDE, Copy path and Copy name. Supports Windows paths and line numbers; executable opening requires confirmation.
- Includes existing Desktop remote sync and per-file-approved read-only transfer controls. Mobile/Web/Cloud services are not deployed by this release.

Windows x64 installer and portable packages are provided. Recovery cannot resurrect a lost inference request or OS process. Canceled inference may still be billed. In-flight tools/subagents, approvals and finalization are not forcibly terminated. Files use system associations; embedded previews and saved IDE preferences are not included. Production Cloud login depends on service availability and was not end-to-end tested for this release.

Validated with mock-provider integration tests, durable-store/reliability tests, actual React browser interactions, isolated Electron handler tests and a production build. OS opening/clipboard/dialog choices are mocked; Save as copies a real temporary file. Existing 0.7.1 assets remain unchanged.

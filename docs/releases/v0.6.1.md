# AporiaX 0.6.1 — Agent-native Tools / Agent 原生工具链

AporiaX 0.6.1 focuses on the tools an autonomous coding Agent uses repeatedly: reading large files, searching repositories, applying robust patches, and managing long-lived terminal processes.

## 中文

- 大文件读取支持行范围、offset 续读、总量信息与 SHA-256。
- 内置 ripgrep，支持正则、Glob、符号和启发式定义/引用搜索。
- Unified Patch 支持多 Hunk、多文件、新建、删除、dry-run、哈希前置条件和失败回滚。
- 新增任务级常驻终端：启动进程、增量读取日志、写 stdin、结束进程树，并在任务结束自动清理。
- 工作区外文件可以在每次单独批准后只读访问，不开放外部写入。
- Extensions Center 可以导入完整 Skill 文件夹和常见 MCP JSON。
- 对话框 `@` 菜单统一提供文件、`@skill:<name>` 与 `@mcp:<id>`。

## English

- Ranged and continued large-file reads with totals and SHA-256 evidence.
- Bundled ripgrep with regex, globs, symbols, and heuristic definition/reference search.
- Multi-file unified patches with create/delete, dry-run, optimistic checks, and rollback.
- Task-scoped persistent terminal processes with incremental logs, stdin, process-tree termination, and automatic cleanup.
- Fresh approval for every read-only file access outside the workspace.
- Local Skill-folder and common MCP-JSON import from the Extensions Center.
- One composer `@` menu for files, `@skill:<name>`, and `@mcp:<id>`.

## Desktop reliability and polish / 桌面可靠性与体验

### 中文

- 停止任务后的“重试本轮”现在会先核对主进程与渲染层运行状态，再以单一事务替换失败轮次；失败原因会直接展示，不再静默无响应。
- Extensions Center 增加更多内置 Skill 预设，并统一中英文发现、导入与 `@mention` 体验。
- 开屏粒子海使用分层采样、可见性暂停与 120 FPS 上限，减少高分辨率窗口中的无效计算。
- 加入本地账户 UI 原型和周额度占位，为后续账号、邀请与移动端联动预留入口；当前不连接服务器，也不保存密码。

### English

- **Retry turn** now reconciles main/renderer run state before atomically replacing a stopped turn; failures are surfaced instead of silently disappearing.
- The Extensions Center adds more first-party Skill presets with bilingual discovery, import, and `@mention` flows.
- The particle-ocean welcome screen uses layered sampling, visibility pausing, and a 120 FPS cap to avoid waste on large displays.
- A local account and weekly-quota UI prototype prepares the desktop surface for future identity, invitation, and mobile companion features; it currently has no server connection and stores no password.

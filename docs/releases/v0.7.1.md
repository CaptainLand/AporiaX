# AporiaX v0.7.1

AporiaX 0.7.1 is a focused Harness performance and reliability release. It reduces unnecessary model work, keeps expensive checks proportional to risk, and makes provider retries safe for streamed responses.

## Faster, cheaper Harness orchestration

- Exploration, verification, and Project Understanding curation now use role-aware low-compute reasoning defaults.
- Review Agents still inherit the parent task's reasoning depth when deeper judgment is useful.
- Nested orchestration runs no longer curate Project Understanding, preventing duplicate or polluted shared context.

## Adaptive self-check policy

- Self-check escalation is now based on change risk instead of file count alone.
- Security, authentication, runtime, package, deployment, and other high-impact paths continue to receive strict review.
- Ordinary multi-file edits in one module no longer trigger an expensive review solely because three files changed.
- Progressive self-check evidence remains version-aware so stale findings cannot seal a newer file revision.

## Smarter Project Understanding updates

- Understanding curation is deferred until the main result is ready, so it no longer delays normal task completion.
- Low-value or non-durable turns are skipped instead of invoking a curator unnecessarily.
- Durable architecture decisions, conventions, commands, preferences, and verified project facts remain eligible for shared Understanding.

## Stream-safe provider retries

- Provider requests are retried only before downstream streamed output has been written.
- Once a response stream has started, failures are surfaced rather than replayed, preventing duplicated or corrupted assistant output.

## Desktop sign-in patch

- The default Aporia Account authorization entry now uses the current AporiaX Web deployment instead of the legacy GitHub Pages URL.
- PKCE S256, exact state validation, loopback callback validation, and Main-process token boundaries remain unchanged.

## Validation and packaging

- Added regression coverage for adaptive self-check, role-aware subagents, deferred Understanding curation, and streamed-provider retry behavior.
- Package version is `0.7.1`.
- Windows x64 installer and portable builds are published with SHA-256 checksums.

## 中文更新说明

AporiaX 0.7.1 是一次聚焦 Harness 性能与可靠性的更新。它减少不必要的模型调用，让昂贵检查与实际风险相匹配，并确保流式响应重试不会破坏已经输出的内容。

### 更快、更省的 Harness 编排

- Explore、Verify 与 Project Understanding Curator 默认使用按角色分配的低计算推理强度。
- Review Agent 在确实需要深度判断时，仍会继承主任务的推理深度。
- 嵌套编排不再重复整理 Project Understanding，减少重复成本与共享上下文污染。

### 按风险触发的自检策略

- 自检升级不再只依据修改文件数量，而是综合判断改动风险。
- 安全、认证、运行时、依赖、部署等高影响路径继续接受严格审查。
- 同一模块中的普通多文件修改，不会仅因文件达到三个便触发昂贵审查。
- 分段自检证据仍与文件版本绑定，旧版本结论不能封印较新的文件内容。

### 更聪明的 Project Understanding 更新

- Understanding Curator 延后到主结果就绪后执行，不再拖慢正常任务交付。
- 普通问候、低价值对话和不具备长期价值的内容会被跳过。
- 已验证的架构决策、项目约定、命令、偏好与调试经验仍会进入共享 Understanding。

### 安全的流式请求重试

- Provider 只会在下游尚未写出流式内容时重试。
- 一旦响应开始输出，后续故障将直接报告，不再重放请求，避免重复文本或损坏回复。

### 桌面登录补丁

- Aporia Account 默认授权入口切换到当前部署的 AporiaX Web。
- 桌面端继续使用 PKCE S256 与本地 loopback callback；Token 安全边界没有变化。

### 验证与打包

- 新增按风险自检、角色化子 Agent、延后 Understanding 整理与流式重试的回归测试。
- 软件包版本为 `0.7.1`。
- Windows x64 安装版与便携版随 SHA-256 校验文件一同发布。

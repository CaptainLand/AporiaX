# AporiaX 0.7.4 — Durable Tasks and Quiet Desktop / 安静桌面与任务落盘

## 中文

### 核心更新

- **分任务存储**：任务历史改为 `aporiax-store` 下每任务一个 JSON，图片与附件原文件按内容哈希落盘。文档抽出的文字仍留在任务 JSON。单个任务超过 200 MB 才跳过该任务，其余照常保存；旧的总文件会自动迁移。
- **原生视觉默认**：自定义 / 灰测模型默认按原生视觉发图。若接口明确拒绝看图，该模型改为仅文本，当前轮去掉图片再试，并提示已改为无视觉。Aporia Cloud 与官方 DeepSeek 仍为仅文本。
- **夜间托盘图标**：任务栏、系统托盘和收纳篮使用夜间 AX；软件内 logo 仍随浅色 / 深色主题切换。
- **去掉刺眼提示**：Witness 不再画出 120 秒停滞告警；登录失败不再把 `APORIAX_CLOUD_REQUEST_FAILED` 常驻在侧栏。后台监控与「Aporia Cloud 未连接」副文案仍保留。
- **回到上次位置**：记住退出前所在任务、Dialogue / Route / Workspace / Understanding 页签和滚动位置。下次启动跳过欢迎页，直接回到该处；任务已删除则退回列表里剩下的第一个。

### 使用与限制

- Windows x64：Setup 安装版和 Portable 便携版。请退出旧版后更新。
- 数据仍在 `%AppData%\Roaming\AporiaX`。分文件存储后不会把全部任务塞进一个 JSON。
- 检查点里的大段 diff 文本仍在任务 JSON 中，受 200 MB 单任务上限约束。
- 未部署或重启 Cloud。未提交或推送 GitHub，除非另行说明。

### 验证

任务存储、视觉能力、Harness 事件、账号面板、原生渲染架构与欢迎页动画相关冒烟已通过。`vite build` 随 `dist:win` 执行。测试使用模拟模型流，不调用付费 API。

## English

- Task history is stored as one JSON file per task plus content-addressed attachment blobs. Extracted document text stays in the task JSON. Only a task whose JSON exceeds 200 MB is skipped; other tasks still save. The legacy all-tasks file migrates on load.
- Custom and preview models default to native vision. If the provider rejects images, that model is switched to text-only, the current turn retries without images, and the UI notes that vision was turned off. Aporia Cloud and official DeepSeek stay text-only.
- The Windows tray, overflow, and taskbar use the night AX mark. In-app logos still follow the selected theme.
- The Witness 120-second stall banner is no longer drawn. Sign-in no longer pins `APORIAX_CLOUD_REQUEST_FAILED` under the account button. Background monitoring and the “Aporia Cloud unavailable” subtitle remain.
- Relaunch restores the last task, view tab, and scroll position instead of always opening welcome or the first task. If that task was deleted, the first remaining task is selected.

Windows x64 installer and portable packages are provided. Quit the previous build before updating. Task data remains under `%AppData%\Roaming\AporiaX`. Cloud was not deployed in this release. Existing 0.7.3 assets remain unchanged.

Validated with task-store, vision, harness-event, account, renderer-architecture, and welcome-particle smokes, plus the production renderer build inside `dist:win`. Tests use mock providers and do not call billed APIs.

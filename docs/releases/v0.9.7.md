# AporiaX 0.9.7 — Local OCR, Git Conflicts, Builders / 本地 OCR、Git 冲突与 Builder

## 中文

GitHub 上一次发布是 **0.9.5**，本包同时带上 0.9.6。

### 0.9.7

- **本地 OCR**：从输入栏、图片/PDF 附件或侧栏预览识别中英文图片与扫描 PDF。首次下载约 4.7 MB 语言模型后在本地运行，不上传文档。
- **Git 冲突**：侧栏对比共同基线、当前分支和合入分支，编辑 1 MiB 内 UTF-8 普通 merge 冲突；确认后再暂存。不自动推送。
- **PR 页**：用已登录的 `gh` 只读查看当前 github.com 仓库与分支的 PR 和检查状态。
- **Builder**：并发 0 / 1 / 2 / 3 / 4 / 6，默认 2；超出排队。修复非 UTF-8 检查点的有损恢复。

### 0.9.6

- 修复中文、空格、括号等交付链接截断。
- Safe 使用独立依赖副本，不再写入宿主 `node_modules`。
- 冲突、取消、超时或回写失败后保留可打开的沙箱恢复目录。

Windows x64 安装版与便携版随 `latest.yml`、blockmap 和 SHA-256 发布。请先退出旧版再更新。当前包未代码签名。

## English

GitHub last published **0.9.5**, so this package also includes 0.9.6.

- Local OCR for Chinese/English images and scanned PDFs after a one-time language download.
- Edit ordinary UTF-8 merge conflicts in the Git sidebar; inspect GitHub PRs and checks read-only.
- Builder concurrency 0 / 1 / 2 / 3 / 4 / 6 (default 2). Non-UTF-8 checkpoints restore as bytes.
- 0.9.6: delivery-link fixes, isolated Safe dependency copies, and kept sandbox recovery snapshots.

Quit the previous build before updating. Windows binaries are unsigned; verify the published SHA-256 checksums.

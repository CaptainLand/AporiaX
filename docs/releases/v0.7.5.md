# AporiaX 0.7.5 — Light Gem Smoke Welcome / 浅色 Gem Smoke 开屏

## 中文

### 核心更新

- **浅色开屏**：欢迎页改为原版 AX PNG 上的 Paper Gem Smoke，背景是很浅的 Mesh 柔流。去掉「A NEW PERSPECTIVE」眉题和页脚口号，保留中英切换。
- **进入按钮**：蓝色胶囊上叠一层可读的 Liquid Metal，文字保持白色。
- **点击切换 logo 效果**：点欢迎页空白（不含进入按钮和语言开关）循环 Gem Smoke、Mesh 柔流、Mesh 漩涡、Grain 波浪、Warp 大理石、Simplex 丝绸、Metaballs 液滴、Liquid Metal。系统「减少动态效果」时只用静态 PNG，不跑着色器。
- **切换不挖空**：新 canvas 画完第一帧再撤旧效果，避免全屏 Mesh 从 logo 位置透出或闪白框。logo 区域不再铺纸色底，和背景融在一起。
- **CSP 与原图**：构建时去掉 Paper 内联样式注入，不使用 `unsafe-inline`。`aporiax-logo-clean.png` 未改（SHA-256 仍为 `5e4c8c77c1f50f577885b7b07b13dc6d91dcce0bb61c5700eef8849d0acf2a35`）。
- **每次启动开屏**：本包打开「每次启动都显示欢迎页」。进入后仍会记住任务、页签和滚动位置，但下次启动会先看到欢迎页。
- **审批通知**：需要确认时，屏幕角落弹出与任务完成类似的通知，展示简要内容，提供确认 / 拒绝。点了立刻关掉；5 秒后未点也会消失，审批仍留在应用内。

### 使用与限制

- Windows x64：Setup 安装版和 Portable 便携版。请退出旧版后更新。
- 数据仍在 `%AppData%\Roaming\AporiaX`。0.7.4 的分任务存储、原生视觉默认和夜间托盘图标保持不变。
- 整页背景 Mesh 与 logo 循环里的 Mesh 是两层，不是重复安装。
- 未部署或重启 Cloud。
- 保留 0.7.4 及更早安装包，不覆盖旧附件。

### 验证

欢迎页 Gem Smoke 浏览器冒烟（含 CSP、原图哈希、上下文丢失回退、减少动态效果）已通过。`vite build` 随 `dist:win` 执行。测试使用模拟模型流，不调用付费 API。

## English

- The opening is the original AX PNG with Paper Gem Smoke on a very light Mesh field. The eyebrow and footer slogan are gone; language switch remains.
- Enter is a blue pill with a readable Liquid Metal overlay and white label.
- Clicking the welcome canvas (not Enter or language) cycles Gem Smoke, Mesh flow, Mesh swirl, Grain waves, Warp marble, Simplex silk, Metaballs, and Liquid Metal. Reduced-motion users keep the static PNG.
- The previous logo frame stays until the next canvas has drawn, so the page Mesh does not flash through a hole. The art slot has no paper-colored card.
- Paper inline canvas CSS is stripped at build time; CSP stays without `unsafe-inline`. The original logo PNG is unchanged.
- This package shows the welcome screen on every launch. Last-task / tab / scroll are still remembered after Enter. 0.7.4 task storage, vision defaults, and tray mark are unchanged.
- Approvals also show a corner toast like the task-complete notice: a short summary with Approve / Deny. It closes immediately on click, or after 5 seconds if ignored; the in-app approval card remains until answered.

Windows x64 installer and portable packages are provided. Quit the previous build before updating. Cloud was not deployed in this release. Existing 0.7.4 assets remain unchanged.

Validated with the welcome Gem Smoke browser smoke (CSP, original-logo hash, context-lost fallback, reduced motion) plus the production renderer build inside `dist:win`. Tests use mock providers and do not call billed APIs.

# AporiaX 0.8.5 — Anchor restore tells the next run

## 中文

- **文件仍只回工作区**：Anchor 回退对话里的文件快照，不删除 Dialogue / Route。
- **后续模型会收到说明**：回退成功后写入 harness 通知，明确那些修改已不在磁盘上，以当前工作区为准；除非用户要求重做，不要继续那次实现。
- **不是新任务**：这条说明不能当作用户授权，压缩时也不会写进用户需求。对话里显示为短标记，而不是用户气泡。

Windows x64 Setup / Portable。请先退出旧版再更新。未部署 Cloud。

## English

- Anchor still restores workspace files only. The conversation remains the audit trail.
- A successful restore appends a harness notice so later model runs re-read current files and do not continue the restored implementation unless the user asks to redo it.
- The notice is not a new user task and cannot become user authorization.

Windows x64 installer and portable packages are provided. Quit the previous build before updating. Cloud was not deployed in this release.

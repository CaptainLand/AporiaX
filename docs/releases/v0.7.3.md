# AporiaX 0.7.3 — Agent-Led Delivery / Agent 主导交付

## 中文

### 核心更新

- **Agent 主导检查**：交付阶段不再因文件数、计划完成或根目录 `package.json` 自动跑测试、分段 Review 或强制自检兜底。主 Agent 通过 `request_self_check` 明确选择相关命令；`run_command` 的 `verification:true` 才记为验证。跳过不会把失败改成通过。
- **诚实交付状态**：允许带着未验证、失败、环境不可用或过期证据交付已有文件。最终说明与界面标题区分通过 / 未验证 / 未通过 / 不可用，不再把「无需独立审查」显示成测试通过。
- **图片预算**：原生视觉请求按图片块估算预算，不再把整段 Base64 当作文本 token。超预算会 `blocked` 并保留已完成工作；含图片的 usage 不用于校准纯文本比例。
- **外部读取与指令**：工作区外只读引用走 `read_external_file` 与既有审批策略；非法路径只返回该工具错误，不泄露外部文件。作用域规则必须完整加载后才执行对应修改。
- **共享写范围锁**：Kernel 与编排共用进程内 Scope Lease；重叠 scope 不能同时打开，失败不会退回父工作区继续写。调度事件带 `runId` / 任务关联。
- **全自动与视觉配置**：合入全自动审批默认、模型级原生视觉/仅文本声明、恢复审批去刷屏，以及既有插话与文件链接能力。安全拒绝、危险删除和不确定副作用核对不受工作流策略影响。

### 使用与限制

- Windows x64：Setup 安装版和 Portable 便携版。请退出旧版后更新；建议先备份重要任务数据。
- 全自动是高权限信任，不是操作系统隔离。工作区外或目标不明的删除、异常恢复中不确定的副作用仍需确认。
- 候选脚本不会自动执行；未运行的检查不得报告为通过。
- Cloud 视觉就绪检查不代表已验证上游可调用；本版本未部署或重启 Cloud 服务。
- 保留 0.7.2 历史安装包，不覆盖旧附件。

### 验证

Agent 主导工作流回归、交付集成、自检协调器、共享 lease、并发合并、恢复审批、视觉能力、工具权限/分发、效率与背景任务，以及 `vite build` 已通过。测试使用模拟模型流，不调用付费 API。

## English

- Delivery no longer auto-runs tests, staged Review, or a mandatory self-check fallback from file count, plan completion, or a root `package.json`. The main agent must select relevant checks; `verification:true` is the only command evidence marker. Skip does not convert a failure into a pass.
- Existing files may be delivered with unverified, failed, unavailable, or stale evidence. The UI and final notice keep those states distinct and do not present “no required review” as a test pass.
- Native vision budget estimates image blocks instead of treating Base64 as text tokens. Over-budget requests return `blocked` and keep saved work. Image usage is not used to calibrate text estimates.
- External read-only references stay on `read_external_file` and the existing approval policy. Invalid workspace paths fail that tool only and do not leak outside files.
- Kernel and orchestration share process-wide scope leases. Overlapping scopes cannot open together, and a conflict does not fall back to the parent workspace. Scheduler events carry run/task correlation.
- Includes full-auto approval defaults, per-model native/text vision declarations, recovery-approval anti-spam, plus the existing live-guidance and file-link work. Safety denials, dangerous deletes, and uncertain side-effect replay still require confirmation.

Windows x64 installer and portable packages are provided. Full-auto is a high-trust policy, not OS isolation. Candidate scripts are not executed automatically. Cloud vision readiness is not an upstream call proof; Cloud was not deployed in this release. Existing 0.7.2 assets remain unchanged.

Validated with agent-led workflow, delivery, coordinator, shared-lease, concurrency, recovery, vision, permission/dispatcher, efficiency and background tests, plus a production renderer build. Tests use mock providers and do not call billed APIs.

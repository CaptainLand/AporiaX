# AporiaX 0.5.0 — 自适应多 Agent Harness / Adaptive Multi-Agent Harness

> **Preview · Windows x64**

AporiaX 0.5.0 是一次面向 Harness 的重要版本升级：从项目级桌面 Agent，进一步发展为一个具有自适应 Agent 预算、冲突安全 Builder、协作契约、可观察执行与桌面后台生命周期的多 Agent Harness。

AporiaX 0.5.0 is a major Harness milestone. It evolves the project-level desktop agent into an adaptive multi-agent Harness with bounded agent budgets, conflict-safe Builders, collaboration contracts, observable execution, and a practical Windows background lifecycle.

### 0.5.0 核心更新

- **Adaptive Agent Budget**：根据任务复杂度自适应分配额外 Agent。简单任务保持 Main-only，复杂任务才受限启用 Explore、Review、Verify、Curator 或 Builder，避免固定多 Agent 带来的额外成本。
- **Builder 编排**：大型可写任务最多启用 2 个 Builder，通过 Task Graph、Scope Lease、独立 Git worktree、dirty-workspace overlay 与合并前冲突检查实现受控并行写入。
- **Collaboration v1**：加入 Shared Contract、确定性 Plan Approval、结构化 Builder handoff、语义分歧检测和有界 mailbox，让并行 Agent 共享约束，而不是无限制互相打断。
- **Main / Review / Verify / Witness**：Main 保持最终集成权；Review 与 Verify 对当前文件版本提供质量检查；Witness 只观察、记录和告警，不修改文件。
- **Harness Architecture**：新增 Event Bus / Hook API、声明式 Agent Definition、Plugin API 与 Core Server 基础，并逐步拆分 Session、Scheduler、Context、Tool、Review 等运行边界。
- **桌面后台体验**：关闭主窗口时任务可继续在 Windows 系统托盘运行，支持托盘恢复与显式退出、系统完成通知、任务耗时和托盘实时运行时间。
- **DeepSeek 上下文缓存**：保持稳定的会话前缀与 cache hit / miss 统计，减少不必要的上下文重建。
- **强制自检与项目理解**：保留渐进式 Review / Verify、自检证据与 Project Understanding / Curator 流程，并让协作上下文进入审核与 Witness 记录。

### 0.5.0 稳定性修复

- Harness v2 smoke fixture 与 Collaboration v1 的 Shared Contract / Plan Approval 规则保持一致。
- 修复短显式 Explore、后台探索和显式委派的 Adaptive Agent Budget 判定。
- 增加中文 `创建` 写入意图识别。
- 增加 `self-check` / `自检` / `复核` / `校验` 验证意图识别。
- 增加显式 Remember / `记住` 持久理解意图，使自动 Curator 获得正确预算。

### Highlights in 0.5.0

- **Adaptive Agent Budget** — allocates additional agents according to task complexity. Simple requests stay Main-only, while more complex tasks can receive bounded Explore, Review, Verify, Curator, or Builder capacity instead of paying a fixed multi-agent cost.
- **Builder orchestration** — eligible large write tasks can use up to two Builders with Task Graph scheduling, Scope Leases, isolated Git worktrees, dirty-workspace overlays, and pre-merge conflict checks.
- **Collaboration v1** — adds Shared Contracts, deterministic Plan Approval, structured Builder handoffs, semantic disagreement detection, and a bounded mailbox so parallel agents share constraints without unrestricted peer interruption.
- **Main / Review / Verify / Witness** — Main keeps final integration authority; Review and Verify perform version-matched quality checks; Witness remains observation-only and never edits files.
- **Harness Architecture** — adds Event Bus / Hook API, declarative Agent definitions, Plugin API, Core Server foundations, and clearer Session, Scheduler, Context, Tool, and Review boundaries.
- **Desktop background experience** — closing the main window can keep work running in the Windows system tray, with tray restore/exit, system completion notifications, elapsed task time, and live tray runtime.
- **DeepSeek context caching** — preserves stable conversation prefixes and cache hit/miss accounting to avoid unnecessary context reconstruction.
- **Mandatory self-check and project understanding** — keeps progressive Review / Verify, verification evidence, Project Understanding / Curator flows, and collaboration context in quality and Witness auditing.

### 0.5.0 stabilization fixes

- Aligned Harness v2 smoke fixtures with Collaboration v1 Shared Contract / Plan Approval rules.
- Fixed Adaptive Agent Budget classification for short explicit Explore requests, background exploration, and explicit delegation.
- Added Chinese `创建` write-intent recognition.
- Added `self-check` / `自检` / `复核` / `校验` verification-intent recognition.
- Added explicit Remember / `记住` durable-understanding handling so automatic Curator flows receive the correct budget.

### Known boundaries

- Core HTTP `taskRpc` remains disabled; credentials, approvals, pause/resume, and mutation control remain in the desktop runtime.
- Close-to-tray keeps the Electron process alive, but active tasks do not yet survive a full process exit/restart.
- Some read-only legacy subagent paths still use compatibility-runtime internals.
- Collaboration v1 intentionally does not provide unrestricted live peer-to-peer agent chat.

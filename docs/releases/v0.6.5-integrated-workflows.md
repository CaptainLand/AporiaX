# v0.6.5 integrated workflows

This integration branch replaces the separate GitHub-workflow and LSP test branches with one end-to-end candidate.

## Managed language intelligence

- TypeScript/JavaScript remains bundled.
- Python can be installed by AporiaX into managed storage with Pyright.
- Go can be installed into managed storage with gopls.
- Rust can be installed through rustup.
- C/C++ clangd can be installed through winget on Windows, Homebrew on macOS, or apt-get on Linux.
- lsp status reports availability/source/installer, and lsp_install is an explicit approval boundary for network/dependency mutation.

## Complete GitHub Agent workflow

AporiaX can now progress from an ordinary workspace folder to a reviewable GitHub PR without asking the user to manually bootstrap Git:

1. git_init
2. explicit git_stage
3. git_commit
4. git_create_branch
5. git_remote_list / approved git_remote_add
6. approved github_repo_create when a remote repository does not exist
7. approved git_push
8. approved github_pr_create
9. github_pr_view / github_pr_checks

Local repository operations are autonomous under workspace-write policy. External routing and remote writes remain approval-gated. Force push remains intentionally unsupported.

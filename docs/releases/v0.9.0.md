# AporiaX 0.9.0 — Workbench Upgrade / 同屏工作台升级

## 中文

这一版重点完善日常使用，把侧边聊天、文档、Git 和终端整合到同屏工作台。

- **侧边聊天**：从空侧栏或「＋」打开，查看当前任务的公开状态、Witness / 工具记录，或切换普通聊天。状态与来源使用可关闭弹窗；模型支持搜索选择，转交主 Agent 前可以编辑并确认。不读取隐藏思维链，不自动调用模型监控。
- **文档查看**：Markdown 支持标题、表格、代码高亮与链接；可切换源码/编辑。Word 支持带格式的分页预览、缩放和适应宽度。远程图片不会静默加载，预览不会执行文档脚本。
- **Git 第六入口**：查看状态、Diff、提交历史，暂存/取消暂存及提交；支持初始化、空目录克隆、本地分支创建/切换、远程与提交身份设置。GitHub 登录通过浏览器和交互终端完成；创建仓库与推送分别确认，默认新仓库为私有。
- **终端升级**：主题跟随、搜索、复制粘贴、字号调整和重命名；切换标签/收起侧栏保留画面与滚动位置，关闭标签才结束会话。修复退出时漏读末尾输出、新建终端清掉已退出日志的问题。
- **输入与光标**：输出到达就唤醒读取，不再等空闲轮询。聚焦时使用高对比常显光标；终端程序主动隐藏光标仍然有效。
- **细节修复**：工作区内绝对路径可正确展示；Windows 安装包与任务栏统一使用更醒目的现有大 AX 图标。

### 下载与升级

- **Setup**：Windows x64 安装版。
- **Portable**：Windows x64 便携版，无需安装。
- 同时提供 `latest.yml`、安装包 `.blockmap` 与 `SHA256SUMS-0.9.0.txt`。

请先退出旧版，再运行安装包或新版便携包。保留原有任务与账号配置，不自动重跑旧命令。固定到任务栏的旧快捷方式若仍显示旧图标，请改为固定新版程序。

当前 Windows 包未配置代码签名证书，系统可能显示“未知发布者”；请核对官方发布来源与 SHA-256 校验值。

### 已知边界

Word 为近似排版；终端历史只在当前应用会话保留，后端输出与滚动历史有上限，不是永久日志。Git 仍依赖本机 Git，GitHub 功能依赖已安装并授权的 `gh`；未提供图形化冲突编辑、强制推送或 PR 管理。本次仅发布 Desktop，不部署 Cloud / Web / Mobile。

## English

- Added independent side chat for public task status and records, or general conversation, with in-app dialogs, model search and explicit handoff to the main Agent. It does not access hidden reasoning or continuously call a model for monitoring.
- Markdown renders headings, tables, code and safe links, with source/edit modes. DOCX supports styled pages, zoom and fit-to-width. Remote images are not loaded silently and document scripts do not execute.
- Git is the sixth sidebar entry: diffs, staging, commits, history, initialization, empty-directory cloning, local branches, remotes, commit identity and interactive GitHub authorization. Creating a repository and pushing remain separate confirmed operations.
- Terminal screens and scroll positions survive tab switches/collapse. Added search, themes, clipboard actions, font sizing and rename; exited sessions retain their logs and drain the full output tail.
- Output-triggered reads remove idle-poll keyboard echo latency. The focused cursor stays visible while application-controlled hiding still works. Packaged Windows icons use the existing larger AX mark.

Windows x64 installer and portable builds include update metadata and SHA-256 checksums. Quit the previous version before updating. Word layout is approximate; terminal history is bounded and session-local. Git/`gh` must be installed separately for Git/GitHub features. This release does not deploy Cloud, Web or Mobile.

Windows binaries are currently unsigned; Windows may display an unknown-publisher warning. Verify the release source and published SHA-256 checksums.

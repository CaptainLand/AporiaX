# AporiaX 0.8.4 — Workbench Browser, Understanding, MCP, Skills

GitHub last published **0.8.0**. This package also includes the 0.8.1–0.8.3 desktop work.

## 中文

### 0.8.4

- **Browser 首屏**：打开网页链接时按真实侧栏尺寸挂上原生 Browser，并微调一次 bounds，Windows 无需再拖分割条才能画出页面。
- **应用更新**：欢迎页结束后检查 GitHub Releases。安装版可在应用内下载并在无任务运行时重启安装；便携版打开下载页。开发运行不检查。
- **Understanding 默认只查看**：已有知识始终可看。注入模型上下文和自动整理要在设置里按工作区打开。过期或文件证据已变的知识只留查看。
- **MCP**：单个服务器发现失败不再打掉整次发现；cursor 循环有上限；大结果通过 `mcp_read_result` 分页，而不是静默截断。
- **Skills**：用户明确选中的 skill 不会被自动匹配上限丢掉。后续消息不再重复叠 skill 文本；超预算的自动 skill 会跳过并留下原因。

### 相对 0.8.0 一并带上的更新

- **0.8.3**：附件可拖到右侧工作台预览副本（输入框里的附件仍在）；侧栏关闭时可拖到最右边缘打开；Builder 数量可选无 / 2 / 3 / 4；去掉标题栏当前模型徽章。
- **0.8.2**：长任务约束在压缩后仍保留；主 Agent 可中途派出有写范围的 Builder；任务可结束为完成 / 部分完成 / 受阻 / 需要输入。
- **0.8.1**：终端可中断当前命令；代码预览有语法高亮；对话图片可在侧栏打开；关闭 Browser 标签会等到页面真正销毁。

### 使用与限制

- Windows x64：Setup 安装版和 Portable 便携版。请先退出旧版再更新。
- 数据仍在 `%AppData%\Roaming\AporiaX`。
- 未部署或重启 Cloud。
- 保留 0.8.0 及更早安装包，不覆盖旧附件。

## English

- Opening a web link attaches the native Browser at the real sidebar size and nudges bounds once so Windows composites it without dragging the splitter.
- After welcome, the app checks GitHub Releases. Installed builds can download in-app and restart to install when idle. Portable builds open the download page.
- Project Understanding is view-only by default. Recalling facts into the model and auto-curation are explicit per-workspace settings; stale or changed file evidence stays out of context.
- MCP discovery isolates server failures, guards cursor loops, and pages large tool results through `mcp_read_result`.
- Explicit Skills are never dropped by the auto-match cap. Follow-up turns no longer double-append skill text.

Also in this jump from 0.8.0: workbench terminal interrupt and syntax-colored previews (0.8.1), long-task reliability and autonomous Builder (0.8.2), composer-to-workbench drag and selectable Builder count (0.8.3).

Windows x64 installer and portable packages are provided. Quit the previous build before updating. Cloud was not deployed in this release. Existing 0.8.0 assets remain unchanged.

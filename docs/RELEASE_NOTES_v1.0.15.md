# AporiaX 1.0.15

- 新增「设置 → 通用 → 任务自动重试」，默认关闭。可用滑动开关开启，直接选择 1–5 次重试（不含首次运行）。
- 遇到可安全重试的临时模型故障时，从最后一个检查点继续，保留计划和已完成的操作，不从头重做。
- 等待期间可以取消；手动重试或发送新消息会取消原先排定的自动重试。
- 登录失效、额度不足或 Cloud 无法确认原请求状态时不自动重发。本版未包含此前 Cloud 偶发 401 的修复。
- 设置新增「社区插件市场」。登录后可浏览和添加 Skill、MCP、子 Agent、皮肤，也可上传、查看自己的投稿和下架已发布的作品。
- 桌面端在投稿前检查重复内容，添加时跳过本机已有的相同配置。桌面和网页共用每周 3 次投稿额度。云端未提供下载次数时，市场按发布时间展示。
- 修复窗口较矮时「通用」设置卡片压住日间、夜间切换按钮的问题。

本版仅提供 Windows x64 安装版。

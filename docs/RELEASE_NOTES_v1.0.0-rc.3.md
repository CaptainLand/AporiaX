# AporiaX 1.0.0 RC3

RC3 整合了 RC2 发布后完成的桌面界面调整。仍是正式 1.0.0 前的候选版本。

## 本次更新

- 统一明暗主题的颜色、字体层级、边框、间距和控件样式，覆盖账户菜单、模型配置、扩展、工具反馈和工作台。
- 重排任务设置面板，改善模型服务、执行模式、审批与任务目标的分组和说明。
- 改进执行记录：当前动作与已结束动作更清晰，轮次选择、状态标记和内联详情更易查看；支持从记录打开侧栏文件。
- 改进项目知识：分类数量、来源说明和详情面板集中展示，保留搜索、项目切换、历史修订与回退。

## 保留的能力与边界

- RC2 的滚动上下文摘要、413 请求大小恢复、Cloud 额度选择、外部本地控制与全局文件权限保持不变。
- 全局工作区外文件权限仍默认关闭；未恢复手机应用、文件/项目/对话远程同步及头像前端展示。
- 本次不调整 Cloud 计费、服务安全规则、账号数据、域名或最低客户端版本。
- 更新入口仍优先 GitHub，网络失败时使用已核对的腾讯云镜像。安装版可下载更新；便携版使用下载入口获取新包。
- 安装包暂未使用 Windows 可信代码签名，系统可能提示未知发布者；请核对官方发布地址与 SHA256。

公开发布的 GitHub Release 将标记为 Latest 以兼容现有默认更新通道；产品本身仍是 RC 候选版，而非正式 1.0.0。

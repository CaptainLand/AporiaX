# 本地验收与发布交接

日期：2026-09-26。**本轮仅本地完成；没有部署、打包、推送、改 GitHub Latest 或调整最低客户端版本。**

## 已完成

- 账户额度页新增全站每日额度：总额来自服务配置（线上既有配置为 ¥5，本轮未连接生产确认或修改），已结算、进行中占用、待核对占用、当前可用以及 UTC 日界重置。网页将重置时间明确显示为北京时间；UTC 00:00 即北京时间 08:00。
- 仅登录用户可读金额汇总；不返回其他账号、设备、请求明细，`Cache-Control: no-store`。结算快照与原有记账处于同一事务锁中。
- 个人额度识别 `actual-usage-v1`：按已结算剩余额度显示，隐藏旧的个人 Reserved 文案。全站的进行中/未知费用保护仍然保留，不把它伪装成个人扣费。
- 网页每 30 秒刷新、回到页面时刷新，可手动刷新；失败、过期、无效数据显示未知，不能变成满额。保留原字体及界面风格，不重新开放头像或手机同步。
- 桌面根据新鲜、确认的个人/全站已结算余额 ≤5% 进入本轮收尾：不新增子任务，现有工作优先保存和交接。Witness 显示一次收尾记录。全站临时占用不会使任务永久进入收尾。
- 新增的 daily/weekly 原因随运行上下文和请求身份保存；旧的 weekly 提示字节不变。重试、恢复、已完成结果复用保持幂等；自带 API 不受限制。
- 安装版更新下载遇到可重试网络失败时，最多切换另一个已配置来源一次。备用清单必须匹配最初版本、文件名、SHA-512、文件大小；校验/证书错误不绕过。electron-updater 读取的元数据也须匹配，防止二次读取变更后误下载。
- 便携版及更新失败时提供 GitHub 与腾讯云备用入口。仅允许既定来源参数，不能通过 IPC 传任意下载网址。便携包是浏览器手动下载，不等同于安装版自动校验/替换。

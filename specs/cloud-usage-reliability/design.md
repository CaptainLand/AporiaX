# 设计

范围沿用用户已确认的改进清单，优先额度、收尾、更新；不做框架迁移。

- Cloud 在 provider-budget 提供统一只读日额度快照，使用与准入/结算相同的数据库事务锁，UTC 日界与 active/unknown 占用。账户 API 暴露鉴权的汇总；网关能力/结算配额携带该快照供桌面读取。
- Web 独立全站额度块，保持既有布局和字体；蓝色正常、琥珀低额、红色耗尽；不可用不能伪装成零占用或满额。仅在可见且登录时轮询，避免个人资料刷新闪烁。
- 桌面 5% 收尾复用已持久化闸门，区分 weekly 和 daily-budget。基于结算余额判断，避免全站临时占用使所有任务永久收尾；不修改已发送请求正文。
- 更新镜像是已配置 HTTPS 账户站点；下载回退只接受与首次清单完全匹配的资产，不吞掉校验错误、不自动安装、不覆盖运行任务。

视觉规范：实用型账户面板；白色背景、#1c2833 正文、#5d7383 次要文字、现有蓝色额度条、#a65b00 警告、#b42318 耗尽。沿用 Inter/Segoe UI 及既有 CSS（品牌例外），只新增左对齐额度块。

# Cloud 额度透明与更新可靠性

2026-09-26。用户已确认按上一轮清单推进；本轮先本地实现与验证，不部署、不发布、不调用真实付费模型。

1. 登录用户访问额度页时，展示全站当日总额、已结算、活动占用、待核对占用、剩余及 UTC 重置时间；仅返回聚合，不含账号或请求明细。
2. 展示额度失败时，显示未知/重试而不是满额；页面可见时定期刷新；个人额度文案与实际结算准入一致。
3. 新请求边界获得确认的全站已结算余额不超过 5% 时，桌面进入一次性收尾；临时活动占用不触发永久收尾。保留幂等请求身份和 BYOK 行为。
4. 更新检查成功但下载失败时，安装版可切换可信备用源；备用资产必须与原版本、文件名、SHA512 和大小一致。便携版提供两个下载来源。
5. 覆盖额度状态/跨日、鉴权、页面错误和刷新、恢复/重启/并发、更新失败与元数据不一致。真实付费模型与真正睡眠恢复另做明确的验收，不把模拟测试称为完成真实验收。
6. 不改每日限额、计费规则、账号数据、隐私同步开关、域名、安全配置或已发布版本。

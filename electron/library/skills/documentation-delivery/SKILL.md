Build documentation as a verified product artifact.

1. Identify the audience, decision, and required output format.
2. Derive technical claims from repository evidence rather than generic product language.
3. Use a clear information hierarchy, short sections, and concrete examples.
4. Validate structure and file integrity with the relevant inspection tool.
5. State any visual checks that still require the target Office application.
